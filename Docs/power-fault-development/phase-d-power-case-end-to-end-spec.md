## 1. 目标

在通用案例平台上新增第二个正式案例：

```text
工控机 24V DC 供电路径异常 / 启动欠压
```

产品界面使用“工控机供电异常”，案例内部设备为 Rockwell ASEM 6300B-EW1。除案例专用内容和视觉外，不复制页面。

## 2. 已确认现场数据

```text
上游启动瞬间电压：23.9V
设备端启动瞬间电压：11.6V
处理后设备端电压：24.0V
处理后启动最低电压：23.7V
Power LED：处理前 OFF，处理后绿色常亮
最终原因：DC-端子松动或接线工艺不良
处理结果：重做端头、复紧端子并恢复供电路径
```

## 5. 首页路由

### 5.1 标准输入

推荐演示输入：

> 站控柜B02工控机电源灯不亮，24V电源模块显示正常，但设备启动一下又掉电，设备端启动时电压明显下降。

### 5.2 意图覆盖

至少覆盖：

- 电源灯不亮；
- 上不了电；
- 开机掉电；
- 反复重启；
- 上游 24V 正常；
- 设备端欠压；
- 启动只有 11.6V；
- 端子松动；
- 6300B 或 Rockwell 工控机。

明确匹配后提交输入即创建新 CaseRun 并直接跳转，不增加确认页。模糊输入才展示候选或追问。

### 5.3 排除和冲突

- 仅 TEMP/FAN、风扇低速和温度升高应命中散热；
- 同时出现温升和掉电时根据排除项及关键测量处理；
- 无设备、告警或关键现象时返回 insufficient；
- RTC、存储或显示异常不能误进供电案例。

## 7. 诊断会诊

### 7.1 Agent 分工

建议保持现有右侧会诊表现，内容由案例数据驱动：

| Agent | 职责 |
| --- | --- |
| 接诊分析 Agent | 整理设备、告警和供电现象 |
| 电源路径 Agent | 比较上游、端子排和设备端电压 |
| 设备手册 Agent | 核对工作电压、针脚和 LED 定义 |
| 安全审查 Agent | 区分带电测量和断电拆装 |
| 综合诊断 Agent | 形成原因排序和下一步 |

### 7.2 核心证据链

```text
Power LED OFF
+ 上游启动瞬间 23.9V
+ 设备端启动瞬间 11.6V
+ 中间端子输出波动
+ DC-端子松动
→ 上游模块能够提供正常电压
→ 中间供电路径存在严重压降
→ 优先检查端子和接线工艺
→ 不能直接判定主板损坏
```

### 7.3 原因排序

1. DC 端子松动或压接不良；
2. 中间端子排接触不良；
3. 线径、极性或应力释放不符合要求；
4. 电源容量不足；
5. 设备内部电源或主板异常。

每项必须列支持证据、反证和下一检查动作。

## 8. 检修预方案

五个大步骤：

1. 保存故障原状并确认作业边界；
2. 分段测量供电路径并核算容量；
3. 正常关机、断电并检查 DC 接线；
4. 修复端子、极性和应力释放；
5. 恢复供电并验证系统与业务。

### 8.1 锁定安全项

- 通知值班负责人；
- 带电测量由具备资质人员执行；
- 禁止带电拆装端子；
- 正常关机；
- 断开上游电源和外设；
- 防静电；
- 烧蚀、发热、变形或异味时立即停止。

这些项不可删除，后端也必须校验。

### 8.2 可编辑范围

允许：

- 修改标题和说明；
- 添加现场特定检查；
- 调整非安全步骤顺序；
- 删除非锁定项；
- 添加观察时间。

确认时生成 `resolvedPlanSnapshot`。

## 9. 检修向导

### 步骤 1：保存原状与边界确认

- 记录 Power LED、上游和设备端状态；
- 保存端子与接线照片；
- 确认业务停机窗口；
- 明确带电测量人员和边界。

完成条件：现场原状、停机授权和安全责任均已记录。

### 步骤 2：分段动态测量

- 核对万用表量程；
- 测上游静态和启动瞬间电压；
- 测端子排输入、输出；
- 测设备端静态和启动最低电压；
- 比较路径压降；
- 核算电源容量余量。

完成条件：关键节点电压及单位完整，能够定位压降区间。

### 步骤 3：关机断电并检查接线

- 正常关机；
- 断开上游电源和外设；
- 确认无电；
- 检查极性、针脚、松动、烧蚀和线径；
- 检查端头剥线、压接和应力释放。

完成条件：断电状态确认，接线缺陷有明确记录。

### 步骤 4：修复端子

- 重做不合格端头；
- 按手册确认针脚和极性；
- 按规定力矩复紧；
- 恢复应力释放；
- 复核无裸露导体和短路风险。

完成条件：所有修复项、使用参数和复核人完整。

### 步骤 5：恢复与观察

- 恢复上游供电；
- 记录 24.0V 和启动最低 23.7V；
- 验证 Power LED；
- 验证 POST、Windows 和业务软件；
- 检查事件日志；
- 按设定时间观察。

完成条件：电气、系统和业务三层恢复，遗留风险已填写。
