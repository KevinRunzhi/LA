# demo1 演示视频分镜脚本

## 1. 使用基线

- 正文视频：`demo1.mp4`，5 分 36.11 秒，画面不再做功能性改录。
- 计划片头：10 秒，只显示项目名称和主视觉，不口播。
- 计划片尾：10 秒，只显示项目标识、团队信息和结束字幕，不口播。
- 预计最终成片：5 分 56.11 秒。
- 所有“成片时间”均已包含片头 10 秒；若片头长度改变，应统一平移正文时间码，不单独改每个分镜。
- 叙事主线：多 Agent 收集资料与现场信息 → 识别设备 → 协同诊断 → 生成并执行检修步骤 → 专家审核 → 知识存储与图谱更新。

## 3. 分段导演说明

### 片头与工程师入口

- 成片时间：00:00.00—00:24.80
- 导演说明：片头前十秒只承担项目名称。正文一开始立即进入工程师视角，口播不解释账号和密码，而是在异常文字与现场图片出现时完成产品定位、多模态接入说明。文件选择器不再补回。

### 检修资料与异常接入

- 成片时间：00:24.80—01:38.37
- 导演说明：检修资料选择不是普通导航菜单，要说成“为当前任务编组依据”。五步接入按页面顺序讲时间、地点、设备、告警和运行状态，右侧 Agent 状态用于证明信息被持续结构化归档。

### 多 Agent 诊断与预方案

- 成片时间：01:38.37—02:16.07
- 导演说明：这是第一处主线强调。口播必须点出故障分析、安全合规、知识检索和协调汇总等职责。预方案的口播从“生成中”页面开始，在大纲完全出现时落到“可修改、可调整”。

### 检修向导

- 成片时间：02:16.07—03:57.17
- 导演说明：向导不是静态操作清单。口播随画面依次说明现场基线、安全准备、专家视频会诊、语音模型、知识库选图和当前步骤问答。第 4 步最长，应把 FAN1/FAN2、接口针脚、断电要求和来源页码讲完整。

### 记录与标准输出

- 成片时间：03:57.17—04:14.13
- 导演说明：作业卡只强调总结性质：任务摘要、过程、证据、风险、结论和恢复参数被整理为两页标准文档。不要把 PDF 说成完整操作手册。

### 专家资源与知识审核

- 成片时间：04:14.13—05:35.30
- 导演说明：专家端先证明知识来源真实可查，再完成三步审核和发布。知识图谱画面出现时讲关系，原始 PDF 出现时讲来源与页码；V1.1 和绿色关系出现时讲版本化存储和知识回流。

### 后台管理与片尾

- 成片时间：05:35.30—05:56.11
- 导演说明：用户管理只占约十秒，一句话即可。正文结束后直接进入十秒片尾，不再追加新的功能说明。

## 4. 画面与口播强关联检查表

| 画面出现时 | 口播必须落到 | 不应提前或延后 |
|---|---|---|
| 异常文字回填、两张图片出现 | 语音识别、多模态资料接入 | 不在专家端再次解释多模态 |
| 检修资料选择状态 | 案例、知识和手册绑定任务 | 不说“简单选择菜单” |
| 多 Agent 运行列表 | 专业 Agent 分工与协调汇总 | 不只泛称“AI 自动分析” |
| 五阶段大纲出现 | Agent 生成、工程师可修改调整 | 不说成不可更改的固定方案 |
| 专家选择与视频窗口 | 专家视频会诊和上下文同步 | 不仅说“联系专家” |
| 语音播放入口 | 已接入语音模型并提供语音向导 | 不提前放在异常语音输入镜头中 |
| 滤网、风扇、接口图切换 | Agent 按当前步骤从知识库选择图片 | 不说图片由人工临时打开 |
| FAN1/FAN2 回答与页码 | 当前步骤问答、手册与知识库依据 | 不只念答案，不遗漏来源 |
| 两页打印预览 | 总结式作业卡和 PDF 导出 | 不复述全部向导步骤 |
| 原始 PDF | 厂商资料真实可查、来源可追溯 | 不在图谱缩放时讲 PDF |
| V1.1 与绿色关系 | 审核发布、版本更新、图谱变化和知识回流 | 不把发布结果说成单纯页面变化 |

## 5. 剪辑与声音建议

- 当前页面操作顺序已经足够完整，不建议为口播重录页面。
- 检修向导长镜头保持现有加速结果，不再整体提速；FAN 接线答案至少保留到“来源文件和页码”可辨认。
- 片头、片尾可使用同一主题音乐；正文音乐建议比口播低 18—22 dB。
- 页面点击音只在“启动诊断、发起会诊、打印、发布”四类关键动作轻量保留，其余不必逐次强化。
- 口播按《demo1 演示视频最终口播稿》统一合成，开头对齐成片 00:10.00。
