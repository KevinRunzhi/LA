系统面向油气场站工控设备检修，支持文字、语音、图片、视频和音频资料接入。工程师登录后，通过语音描述异常，识别文字自动回填，并接入两张现场图片。

接诊前，工程师从历史案例、检修知识和厂商手册中选择资料，供后续 Agent 检索、引用和追溯。

异常接入首先确认发生时间和地点。信息收集 Agent 按步骤保留原始描述，将发生时刻、站点、控制中心和站控柜位置结构化归档，确保后续诊断始终对应同一设备、同一现场，并在检修记录与作业卡中保持一致。

随后识别设备和告警对象。设备识别 Agent 结合事件描述、现场图片和已选资料，锁定工控机及温度与风扇告警，并补全设备角色和运行对象，避免型号、位置和设备发生混淆。

接着补充灯态、蜂鸣器、风扇转速、系统温度和 CPU 温度，并关联两张现场图片。检修智能体将这些观测统一归档，使零散的非结构化现象转化为可计算、可核验的诊断条件，为后续研判提供统一输入。

信息确认，多 Agent 会诊启动。故障分析 Agent 判断散热方向，安全合规 Agent 校验操作边界，知识检索 Agent 从案例和手册中查找依据，最终由协调 Agent 汇总为统一结论。

综合判断优先指向风道、滤网、风扇低速和温升问题。

Agent 汇总诊断结论、知识依据和安全约束，以大纲形式自动生成五阶段检修预方案。工程师可调整步骤和顺序，确认后进入执行。

向导第一步核对告警、温度、风扇转速和设备位置，建立可比较的现场基线。

第二步进入安全准备，逐项确认通知负责人、正常关机、断开电源、等待冷却和防静电，安全项确认后方可继续。遇到复杂问题，工程师可在当前步骤发起专家视频会诊；系统同步设备、异常和检修上下文，会诊结束后继续原有流程。

第三步检查机柜环境和风道。Agent 根据知识库自动匹配结构示意图，并通过接入的语音模型播报当前步骤、风险和检查要点，为现场提供连续的语音向导。

第四步检查滤网、风扇和接线。随着检查推进，向导依次切换门滤网、风扇结构和主板接口图，这些指导图片均由 Agent 结合当前步骤从知识库自动选择。工程师对接线顺序存在疑问，可直接向检修智能体提问。系统综合设备信息、当前步骤、用户手册和知识条目，给出风扇一、风扇二的对应关系、接口针脚和断电要求，并列出来源文件和页码。问题、回答和引用依据均绑定当前步骤，使现场操作能够核验和追溯，并为后续知识审核保留上下文。

最后恢复供电，复核告警、风扇转速、系统温度和 CPU 温度，并持续观察运行状态，确认设备恢复稳定。

检修完成后，系统自动汇总操作过程、现场证据、安全风险和恢复参数，生成检修记录及两页标准作业卡，可直接打印或导出 P D F。

记录列表同时沉淀不同型号、不同故障领域的检修结果。

切换专家端，工作台集中呈现待审核案例、知识资源、最新版本动态和统计概览。

专家可在全局知识图谱中查看设备、现象、原因、阈值和措施之间的关系，也能进入检修知识库，浏览结构化知识和不同型号的厂商手册。专家还可在图谱与资料之间快速切换。原始 P D F 可以直接打开并定位，知识条目保留适用设备、来源文件和页码，确保诊断依据能够回溯到真实资料。

专家审核分为三步：先核对并修正案例，再确认知识条目和图谱关系，最后检查发布摘要。系统把现场经验提炼为适用条件、判断规则、处理措施和验证标准，并保留案例、资料和版本来源，专家拥有最终确认权。

发布后，K B 零零八从 V 一点零更新为 V 一点一，六条关系正式进入诊断路径。知识图谱同步突出本次新增和修改，完成从现场检修、案例总结、专家审核到知识存储，再回流后续诊断的闭环。

管理员页面集中维护工程师、专家和账号状态，支持查询、编辑和启停，为多角色协作与系统运行提供基础保障。
