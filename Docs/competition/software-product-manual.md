## 1. 引言

### 1.1 编写目的

本文档用于介绍“工控设备智能检修与知识作业系统”的产品定位、适用范围、功能组成、访问方式和操作方法，帮助用户了解软件能够完成的工作，并按照统一流程使用现场异常接入、知识检索、智能辅助诊断、标准化检修、专家审核、检修记录、作业卡、知识库和知识图谱等功能。

本文档重点回答以下问题：

1. 软件适用于哪些设备检修场景；
2. 工程师、专家和用户管理员分别能够使用哪些功能；
3. 用户如何从现场异常开始完成一次检修任务；
4. 用户如何查看、维护和更新检修知识；
5. 操作过程中出现异常或提示时应当如何处理。

本文档不说明程序源代码、数据库结构和内部接口设计，不记录测试执行结果，也不提供服务器安装命令。上述内容分别由《软件功能设计文档》《软件功能测试报告》和《软件安装包及部署文档》说明。

## 2. 产品概述

### 2.1 软件名称与版本

软件正式名称为：

> 工控设备智能检修与知识作业系统

本文档对应软件版本为V1.0。用户查看软件页面、检修记录或作业卡时，应注意其所属软件版本、业务记录版本和知识版本，以便进行问题复核和来源追溯。

### 2.2 产品定位

工控设备智能检修与知识作业系统是一套面向工业现场检修工程师、检修专家和用户管理员的B/S软件产品。系统以现场设备异常为起点，将多模态现场材料、设备信息、运行参数、历史检修案例、结构化检修知识和厂商手册组织到同一检修任务中，辅助用户完成故障判断、检修方案确认、步骤化作业、恢复验证、检修记录、专家审核和知识更新。

系统不是单独的资料查询工具，也不是替代现场人员作出设备控制决定的自动执行系统。产品通过“资料有来源、建议可复核、步骤有约束、结果需确认、经验可回流”的方式，把现场检修过程与组织知识管理连接起来。

### 2.3 建设目标

产品建设目标包括：

1. 建立统一的工控设备检修知识入口，集中使用案例、知识条目和厂商手册；
2. 统一接入文字、语音、图片、视频、音频和运行参数等现场信息；
3. 根据设备、故障现象和现场材料辅助工程师检索资料并判断故障方向；
4. 将诊断建议转化为可修改、可确认和可执行的检修步骤；
5. 通过安全提醒、强制检查和人工确认提高检修过程规范性；
6. 自动形成结构统一、可查询、可打印和可追溯的检修记录及作业卡；
7. 通过专家审核控制案例归档和知识更新质量；
8. 将有效检修经验持续更新到检修知识库和知识图谱；
9. 支持扩展新的设备品牌、型号、部件、故障领域和检修资料；
10. 支持在LoongArch架构和银河麒麟高级服务器操作系统环境中运行。

### 2.4 适用场景

本软件适用于工业现场设备运行维护、故障检修、专家审核和知识管理等场景，主要包括：

1. **场站异常接入。** 值班或检修人员发现告警、异响、温度变化、显示异常、启动失败或通信中断后，使用文字或语音描述异常，并接入现场图片、视频、音频和运行参数。
2. **设备资料快速查找。** 工程师根据设备类型、品牌、型号和故障领域，从检修案例、知识条目和不同厂商手册中筛选适用资料。
3. **多模态辅助诊断。** 系统综合现场描述、材料、设备信息、告警和检修知识，给出故障方向、判断理由、风险提示和建议处理方向。
4. **标准化现场检修。** 工程师确认检修预方案后，按照检修向导逐步完成检查、处理、安全确认和现场结果记录。
5. **当前步骤专项问答。** 工程师围绕当前检修步骤询问接线、转速、温度、阈值和操作方法，系统结合当前设备资料和步骤上下文提供说明。
6. **恢复运行确认。** 检修完成后记录告警、温度、转速、设备运行状态和观察结果，确认设备是否具备恢复条件。
7. **检修档案输出。** 系统汇总检修事实和结果，形成检修记录以及适合A4打印和归档的PDF作业卡。
8. **专家协同审核。** 专家核对现场事实、诊断依据、处理措施和恢复结果，修正结论并决定是否通过审核。
9. **知识持续更新。** 审核通过的案例形成新的历史案例、知识版本或知识图谱关系，并用于后续同类检修任务。
10. **人员与组织管理。** 用户管理员维护工程师、专家、场站、班组、机构、专业方向和账号启停状态。
11. **培训与经验传承。** 新员工通过案例、知识条目、手册和知识图谱学习设备结构、故障关系、检修方法和安全要求。
12. **巡检与预防性维护。** 运维人员参考滤网、风扇、存储、电池、接口、告警和安装环境等知识开展检查，提前发现潜在风险。

### 2.5 适用设备范围

系统首期以工业计算机及相关部件为主要对象，支持的设备和部件范围包括：

- 机架式工控机；
- 箱式工控机；
- 面板式工控机；
- 工业计算机主板、底板、内存和扩展部件；
- 电源模块、冗余供电组件和配电附件；
- 风扇、滤网、散热器和机箱风道；
- HDD、SSD等存储介质；
- 网络、串口、USB和总线通信接口；
- 显示部件、RTC电池、监控模块、指示灯和蜂鸣器。

用户在使用具体设备资料时，应优先选择与目标品牌、型号和硬件版本一致的内容。同系列或同类设备资料只能作为参考，涉及接线位置、拆装方式、备件型号和参数阈值时，需要再次核对目标设备手册。

### 2.6 适用故障范围

产品通过检修知识库和知识图谱覆盖多个故障领域，不局限于单一散热问题。

| 一级故障领域 | 主要内容 | 典型异常 |
| --- | --- | --- |
| 环境工况异常 | 温度、湿度、粉尘、风道、安装、接地和机械环境 | 温度超标、低温无加温、温度凝露、滤网堵塞、粉尘积聚、风道遮挡、振动冲击和接地不良 |
| 供电系统故障 | 外部供电、电源模块、冗余电源、配电附件和电压监测 | 电压超范围、电源老化、冗余电源单路损坏、保险丝不匹配、接线松动或插反、输出电压偏移 |
| 硬件部件故障 | 风扇、存储、主板、底板、内存、扩展卡、显示和RTC电池 | 风扇低速或停转、存储健康告警、启动盘故障、内存异常、扩展卡接触不良、黑屏花屏和RTC电池亏电 |
| 配置与维护异常 | 固件、操作系统、驱动、接口配置、安装检修和备件管理 | POST中止、启动顺序错误、镜像损坏、驱动不匹配、通信参数错误、带电拆装、长期未清理和配件混用 |
| 监控与告警异常 | 温度、风扇、电压、存储、网络、指示灯、蜂鸣器和远程监控 | 监控代理离线、LED或蜂鸣器失效、SMBus/PMBus通信中断、远程告警失败和持续误报警 |

散热异常在产品中具有较完整的现象、判据、原因、检查、处理和恢复验证知识链，可用于展示完整检修闭环。其他故障领域通过设备手册、知识条目、历史案例和图谱关系提供检索、诊断和扩展支持。

### 2.7 产品主要特点

#### 2.7.1 多模态现场信息统一接入

用户可以在同一异常任务中组织文字描述、短时语音输入、图片、视频、音频、设备信息、告警和运行参数。语音识别结果先回填为可编辑文字，经用户确认后再进入业务记录，避免未经检查的识别结果直接成为现场事实。

#### 2.7.2 多来源检修知识统一使用

检修资料覆盖历史案例、结构化知识条目和厂商设备手册。用户可以按设备、型号、故障领域、资料类型和关键词筛选，也可以使用系统根据当前任务推荐的资料。每项知识保留来源和适用范围。

#### 2.7.3 具有依据的智能辅助诊断

系统将现场事实与知识检索结果共同用于辅助诊断，输出故障方向、判断理由、风险提示和建议处理方向，并展示主要资料依据。信息不足时，系统提示用户补充，而不是把不确定内容作为确定结论。

#### 2.7.4 可确认的标准检修过程

检修预方案由多个阶段和步骤组成，工程师可以根据现场条件修改和确认。断电、挂牌、冷却、防静电等强制安全内容受到保护。检修向导逐步记录检查项、处理结果、材料和完成状态。

#### 2.7.5 面向当前步骤的智能问答

工程师可通过文字或语音围绕当前步骤追问。系统结合目标设备、当前方案、步骤目标、已选资料和已经记录的现场结果回答，并在涉及型号专用信息时提示资料适用范围。

#### 2.7.6 专家审核与知识质量控制

检修完成后由专家核对事实、诊断、处理和恢复结果。未通过审核的内容不会直接进入正式知识库。专家可以修正结论、填写意见、退回补充，或确认案例归档并形成知识更新。

#### 2.7.7 检修记录和PDF作业卡输出

系统根据完整任务自动组织检修记录，并生成内容清晰、适合两页A4纸张阅读和打印的PDF作业卡。作业卡汇总故障现象、设备信息、诊断结论、实际措施、恢复参数、安全要求、风险和来源信息。

#### 2.7.8 知识库与知识图谱协同

检修知识库保存可阅读和检索的案例、知识条目和手册，知识图谱表达设备、部件、故障、现象、原因、措施和依据之间的关系。用户既可以从资料正文理解知识，也可以从图谱查看知识关联。

#### 2.7.9 检修经验持续回流

审核通过的检修经验可以转化为正式历史案例、新的知识版本和图谱关系。知识更新保留来源案例、审核人员、内容差异和发布时间，使后续工程师能够使用已经确认的新知识。

#### 2.7.10 三类角色职责隔离

工程师负责现场检修，专家负责专业审核和知识维护，用户管理员负责账号和组织管理。三类角色进入各自工作区，重要操作由系统权限和状态共同限制。

## 3. 产品运行与访问说明

### 3.1 产品运行方式

本软件采用B/S运行方式。系统服务部署在指定服务器环境中，用户无需在个人计算机安装独立客户端，通过受支持的PC浏览器访问系统地址即可使用相应功能。

软件服务端支持部署在LoongArch架构和银河麒麟高级服务器操作系统环境中。服务器安装、初始化、服务启动、端口配置和健康检查方法由《软件安装包及部署文档》说明。普通用户只需要获得系统访问地址和有效账号。

产品运行时可能访问智能模型服务以完成语音识别、文档识别、知识检索、智能诊断和问答。外部智能服务暂时不可用时，系统会显示相应状态；已经保存的任务、检修记录和已发布知识仍按照系统可用范围提供访问。

### 3.2 用户终端要求

用户终端应满足以下基本条件：

| 项目 | 使用要求 |
| --- | --- |
| 终端类型 | 能够运行常用现代浏览器的PC |
| 显示方式 | 建议使用桌面显示器并保持浏览器正常缩放比例 |
| 网络 | 能够访问系统部署地址；上传视频或大文件时应保持网络稳定 |
| 浏览器 | 使用单位允许且受支持的现代浏览器版本 |
| 输入设备 | 键盘和鼠标 |
| 麦克风 | 使用语音输入功能时需要，并由用户主动授权 |
| 音频输出 | 使用检修步骤语音播报时需要扬声器或耳机 |
| 文件读取 | 上传现场图片、视频、音频或资料时需要访问本地文件 |
| PDF工具 | 浏览器通常可直接查看作业卡；也可使用单位允许的PDF阅读工具 |

浏览器被禁止使用麦克风时，文字输入仍可正常使用。浏览器不支持某种现场文件预览时，用户可根据页面提示下载查看或更换支持的文件格式。

### 3.4 登录与退出

#### 3.4.1 用户登录

系统支持一线检修工程师、检修专家和用户管理员使用各自账号登录。登录时执行以下操作：

1. 在“登录账号”输入框填写本人账号；
2. 在“密码”输入框填写当前密码；
3. 检查输入内容后选择“登录”；
4. 等待系统完成身份和账号状态校验；

用户不需要在登录页面自行选择角色。账号角色由系统统一维护，登录后自动进入工程师端、专家端或用户管理后台。账号或密码错误时，页面给出统一登录失败提示；账号已停用时，用户应联系用户管理员处理。

| 检修专家 | 专家工作台 | 待审核任务、历史案例、检修知识库、知识图谱和专家资料 |

如果页面显示的姓名、角色或组织信息不正确，用户不应继续执行业务操作，应退出后联系用户管理员核对账号资料。

### 3.6 通用操作与状态提示

#### 3.6.1 常用操作

产品页面主要使用以下通用操作：

| 操作 | 作用 | 使用注意事项 |
| --- | --- | --- |
| 新增 | 创建异常、步骤、知识或用户等对象 | 提交前检查必填信息和适用范围 |
| 编辑 | 修改允许变更的资料或业务内容 | 已归档或已发布内容通常需要创建新版本 |
| 保存草稿 | 保存尚未确认的阶段性内容 | 草稿不等于提交、审核通过或发布 |
| 确认 | 确认事实、方案、步骤或恢复结果 | 确认后可能进入下一业务阶段 |
| 提交 | 将完整内容提交给下一处理角色或流程 | 提交前检查材料、必填项和安全确认 |
| 取消 | 关闭当前操作或撤销未提交内容 | 已提交业务不能通过普通取消直接删除 |
| 搜索与筛选 | 根据关键词、状态、设备或类型缩小结果范围 | 清除筛选后可恢复完整列表 |
| 查看详情 | 打开记录、资料、节点或任务的完整信息 | 查看后可根据权限返回或进入后续操作 |
| 下载或导出 | 获取原始资料或PDF作业卡 | 注意文件用途、权限和本地保存位置 |

#### 3.6.2 页面状态反馈

系统通过文字、颜色、图标、进度和按钮状态反馈当前操作结果。常见状态包括：

- **待处理：** 对象已建立，等待用户或后台任务开始处理；
- **处理中：** 上传、识别、诊断、检索、生成或发布正在执行；
- **待确认：** 系统已经形成结果，需要用户检查并确认；
- **已完成：** 当前操作成功，结果已保存；
- **已失败：** 当前操作未完成，页面显示原因和允许的处理方式；
- **已阻断：** 缺少必要条件、安全确认或权限，暂时不能继续；
- **已归档：** 业务已经闭环，主要内容以只读方式保留。

按钮处于加载状态时，用户不应连续重复点击。页面长时间没有变化时，应先查看状态提示和网络连接，再根据页面提供的“重试”“刷新状态”或“返回”操作处理。

#### 3.6.3 必填、警告与确认

带必填标识的字段必须填写后才能提交。字段格式错误时，页面在对应位置给出提示，用户修正后重新提交。危险操作、强制安全步骤、恢复上电、专家审核通过、知识发布、图谱发布、账号停用和密码重置等重要操作会显示醒目的警告或确认信息。

用户应阅读确认内容，不得在未核对对象、影响范围和现场条件的情况下直接继续。智能建议、系统推荐值、OCR文字和语音识别文字均应由相应责任人员确认。

#### 3.6.4 列表、详情与返回

列表页面通常提供关键词搜索、状态筛选、类型筛选、分页和详情入口。用户进入详情后，应使用页面提供的返回操作回到原列表，以尽量保留此前筛选条件。

同一业务对象在不同页面显示时使用稳定业务编号。用户发现名称相同但编号不同的任务、记录或资料时，应根据编号、设备、时间和状态确认目标，避免操作错误对象。

#### 3.6.5 文件与语音操作

上传文件前，用户应确认文件内容、格式和业务用途。页面显示上传或处理完成后，文件才可以参与后续任务。删除尚未提交的材料时应确认是否仍需要保留；已经进入归档记录或正式知识的文件不能通过普通操作直接删除。

使用语音输入时，用户主动启动录音并授权浏览器访问麦克风。录音完成后，系统将识别文字回填输入区，用户可以修改、取消或确认。语音输入失败不影响键盘输入。作为现场证据保存的音频材料与只用于文字输入的短时语音使用不同入口，用户应根据实际用途选择。

#### 3.6.6 操作中断与数据保存

在异常接入、检修步骤、专家审核和知识编辑等较长操作中，用户应及时保存草稿或阶段结果。页面刷新、会话失效或网络中断后，重新进入对应任务时，系统恢复已经保存的业务内容；尚未保存的输入可能需要重新填写。

如果系统提示数据已被其他用户修改，用户应刷新并查看最新内容，不应反复提交旧页面。需要保留的修订内容可复制后与最新版本比较，再重新提交。

## 4. 用户角色与权限

### 4.1 一线检修工程师

一线检修工程师是现场异常接入、检修执行和结果记录的主要使用者。工程师通过工程师工作台进入检修主流程，以本人负责的设备、异常和检修任务为工作对象。

工程师主要完成以下工作：

- 查看所属场站、班组、设备状态、待处理异常和最近检修记录；
- 使用文字或语音录入现场异常；
- 接入图片、视频、设备异响等现场材料；
- 选择与当前设备和故障相关的案例、知识条目和厂商手册；
- 确认设备型号、异常地点、告警状态和运行参数；
- 启动知识检索和智能辅助诊断，查看诊断理由与资料依据；
- 通过文字或语音对诊断结论和当前检修步骤进行追问；
- 修改并确认检修预方案；
- 按检修向导逐项执行检查、处理和安全确认；
- 记录恢复后的告警、温度、转速、运行状态和观察结果；
- 生成检修记录和PDF作业卡；
- 将完整检修结果提交专家审核；
- 查看已发布知识和知识图谱，使用专家审核后的最新知识。

工程师可以修改本人当前任务中允许编辑的内容，但不能删除强制安全步骤，不能直接审核案例，不能修改或发布正式知识，也不能维护其他用户账号。归档后的检修记录以只读方式保留。

### 4.2 检修专家

检修专家是检修质量审核和专业知识维护的主要使用者。专家通过专家工作台查看待审核任务、最近案例、历史案例和知识资产，并在授权专业范围内进行审核与发布。

专家主要完成以下工作：

- 查看待审核、审核中和已归档的检修任务；
- 查看工程师提交的现场事实、图片、视频、音频和资料依据；
- 核对诊断建议、检修方案、步骤执行和恢复验证；
- 修正故障原因、诊断结论和实际处理方法；
- 保存审核草稿，填写审核意见和知识更新说明；
- 将信息不足的任务退回工程师补充；
- 审核通过符合要求的案例并完成归档；
- 查看、增加、编辑和发布检修知识条目；
- 查看全局知识图谱和本次新增与修改内容；
- 新增或修改图谱节点及关系，并确认图谱变更；
- 验证新知识能否被相似异常检索；
- 维护个人所属机构、专业方向和可审核设备范围。

专家可以查看已发布的公共知识，并处理授权范围内的专业内容，但不能通过专家工作台新增、停用用户或重置其他用户密码。专家审核不替代现场工程师的操作确认，现场事实和实际执行结果仍保留原责任人员。

### 4.3 用户管理员

用户管理员负责工程师和专家账号、角色及组织归属的统一维护。用户管理员登录后进入独立的用户管理后台，不进入工程师检修流程和专家知识维护流程。

用户管理员主要完成以下工作：

- 查看工程师、专家、正常账号和停用账号数量；
- 按角色筛选用户；
- 按姓名、登录账号和组织归属搜索用户；
- 查看用户编号、姓名、账号、角色、组织和账号状态；
- 新增工程师或专家账号；
- 编辑用户姓名、登录账号、角色和组织归属；
- 维护工程师所属场站和班组；
- 维护专家所属机构和专业方向；
- 启用或停用工程师、专家账号；
- 发起用户密码重置；
- 查看账号管理操作的执行结果。

用户管理员不具备检修执行、专家审核、知识编辑和图谱编辑权限，也不因管理账号而获得系统部署、数据库维护或模型配置权限。用户管理操作保留操作人、时间、目标用户和结果信息。

### 4.4 角色功能边界

系统按照用户职责划分工作区和操作权限。页面菜单用于帮助用户定位功能，实际操作还会根据账号状态、业务对象归属和当前业务状态进行检查。

| 功能 | 工程师 | 专家 | 用户管理员 |
| --- | --- | --- | --- |
| 登录和安全退出 | 允许 | 允许 | 允许 |
| 查看本人及组织信息 | 允许 | 允许 | 允许 |
| 创建现场异常 | 允许 | 不提供 | 不提供 |
| 接入现场多模态材料 | 允许 | 审核时查看 | 不提供 |
| 选择和查看已发布检修资料 | 允许 | 允许 | 不提供 |
| 使用智能辅助诊断和步骤问答 | 允许 | 可用于专业复核 | 不提供 |
| 修改并确认检修预方案 | 允许 | 审核时查看和提出修正 | 不提供 |
| 执行检修步骤和恢复验证 | 允许 | 审核时只读查看 | 不提供 |
| 生成检修记录和作业卡 | 允许 | 查看审核对象的记录和作业卡 | 不提供 |
| 提交检修案例审核 | 允许 | 接收并处理 | 不提供 |
| 审核和归档检修案例 | 不允许 | 允许 | 不允许 |
| 查看已发布知识和图谱 | 允许 | 允许 | 不提供 |
| 编辑、审核和发布知识 | 不允许 | 允许 | 不允许 |
| 编辑、审核和发布图谱关系 | 不允许 | 允许 | 不允许 |
| 新增和编辑工程师或专家 | 不允许 | 不允许 | 允许 |
| 启停账号和重置密码 | 不允许 | 不允许 | 允许 |

出现以下情况时，即使页面中曾经显示某项操作，系统仍会阻止继续：

- 当前账号已经停用或登录状态失效；
- 用户角色不具备目标功能权限；
- 目标任务、记录、知识或用户不在当前用户的数据范围内；
- 目标对象已经归档、发布或由其他人员更新；
- 当前任务尚未完成必要的前置步骤；
- 强制安全确认、恢复验证或审核材料不完整。

### 4.5 账号状态与访问限制

#### 4.5.1 正常账号

正常账号可以使用账号和密码登录，并进入对应角色工作区。用户应使用本人账号操作，不得多人共用同一登录账号。用户姓名、角色或组织归属发生变化后，以系统中最新有效资料作为新业务操作依据，历史记录仍保留原业务快照。

#### 4.5.2 停用账号

停用账号不能建立新的登录会话。已经登录的账号在系统再次校验状态时停止继续访问。账号停用不会删除该用户已经完成的检修记录、专家审核和知识发布记录，历史内容仍保留人员编号、姓名和操作时间。

用户发现账号被停用时，应联系用户管理员核对停用原因。只有具备相应权限的用户管理员可以重新启用工程师或专家账号。

#### 4.5.3 密码重置

用户忘记密码或根据安全要求需要更换凭据时，由用户管理员发起密码重置。重置后，用户应按照管理要求取得新凭据并及时完成登录验证。页面和普通操作记录不会长期展示用户明文密码。

#### 4.5.4 会话失效

登录持续时间超过系统允许范围、账号状态发生变化或系统执行安全退出后，当前会话可能失效。页面提示重新登录时，用户应先确认当前输入是否已经保存，再返回登录页面。重新登录后，可以继续访问已经保存且仍有权限处理的任务。

#### 5.2.1 现场异常接入

工程师从工作台进入现场异常接入，填写异常描述，按需使用语音输入，并接入图片、视频和音频材料。已接入内容形成当前任务的现场信息基础。

#### 5.2.2 资料选择与信息确认

工程师从案例、知识条目和设备手册中选择当前检修资料，并确认异常发生时间、地点、设备品牌型号、告警和运行参数。系统形成可供诊断使用的现场信息摘要。

#### 5.2.3 知识检索与辅助诊断

系统根据现场事实、设备信息、检修资料包和已发布知识查找相关内容，形成故障方向、判断理由、风险提示和建议处理方向。工程师可以追问并确认诊断结果。

#### 5.2.4 检修预方案与步骤执行

系统根据诊断结果形成检修预方案。工程师修改并确认后，按照向导逐步完成安全确认、检查、处理、材料补充和步骤结果记录。执行过程中可以围绕当前步骤进行文字或语音追问。

#### 5.2.5 恢复验证与结果输出

检修处理完成后，工程师检查复装和恢复上电条件，记录告警、转速、温度、运行状态、观察时间和遗留风险。恢复结果确认后，系统形成检修记录和PDF作业卡。

#### 5.2.6 专家审核与知识回流

工程师将完整记录提交专家审核。专家查看事实、材料、诊断依据、执行步骤和恢复结果，必要时退回补充或修正结论。审核通过后，案例归档，并可形成新的知识版本和图谱关系，供后续任务检索和诊断使用。

## 6. 工程师端使用说明

工程师端以一次检修任务为操作主线。本章按照工程师实际使用顺序，说明从工作台接入异常、选择资料、确认信息、启动诊断、确认方案、执行检修、恢复验证到形成记录的操作方法。

工程师执行任何检修操作前，应确认当前用户、场站、设备、任务编号和任务阶段。涉及断电、拆装、接线、恢复上电等操作时，应同时遵守设备手册、现场制度和安全作业要求。

### 6.1 工程师工作台

#### 6.1.1 工作台信息组成

工程师登录后默认进入“工作台”。工作台集中展示当前值班信息、场站设备、现场接诊入口、材料接入入口、快速接诊入口和近期检修动态。

工作台主要区域如下：

| 区域 | 显示内容 | 工程师需要确认的事项 |
| --- | --- | --- |
| 值班信息 | 当前工程师、场站、站控区域和待处理数量 | 姓名、场站和班组是否正确 |
| 设备对象 | 工控机、控制器、电源、通信模块和控制柜环境等对象 | 当前异常所属设备是否已接入台账 |
| 现场接诊 | 异常描述、开始接诊和现场采集入口 | 先记录现象，不提前填写未经确认的故障原因 |
| 现场采集 | 故障图片、故障视频、故障录音和检修资料 | 材料是否属于当前异常，内容是否清晰 |
| 快速接诊 | 按温度、风扇、通信、供电、状态灯和数据上传等类型发起 | 快速入口是否与现场主要现象一致 |
| 接诊状态 | 异常来源、已知材料、建议动作、待审核和知识状态 | 当前任务是否存在未完成或待审核事项 |
| 业务链路 | 现场接诊、设备识别、资料检索、智能分析、安全校验、作业卡和知识回流 | 了解完整流程及当前所在阶段 |

> 建议截图展示值班信息、设备对象、现场接诊、现场采集、快速接诊和接诊状态区域，并使用编号标注各区域。

#### 6.1.2 设备与异常信息

工作台左侧或设备区域展示当前场站已经接入的设备对象。工程师选择设备对象时，应核对：

1. 设备类别是否与现场对象一致；
2. 设备品牌和型号是否正确；
3. 设备所在场站、区域和机柜是否正确；
4. 设备在现场承担的业务角色是否正确；
5. 当前异常是否确实发生在该设备或其相关部件。

设备对象卡片用于帮助工程师定位现场对象，不能代替后续“设备与故障信息确认”。当台账信息与现场铭牌、标签或实际安装位置不一致时，工程师应在异常接入过程中选择正确内容，并向设备管理人员反馈台账差异。

#### 6.1.3 当前任务与最近记录

工作台通过状态卡片或任务摘要展示待处理异常、当前检修任务、待专家审核记录和最近检修结果。工程师进入任务前，应根据以下信息确认目标：

- 检修任务编号；
- 设备名称和型号；
- 异常发生地点；
- 故障现象摘要；
- 当前业务阶段；
- 最近更新时间；
- 当前负责人或提交人。

选择正在处理的任务后，系统进入该任务最近保存的阶段。选择已归档记录时，系统以只读方式打开记录详情。对于名称相近的设备，应以任务编号、设备编号、位置和发生时间共同判断，避免进入错误任务。

#### 6.1.4 快速功能入口

工程师可以通过以下方式开始工作：

1. 在“描述现场现象”输入框填写异常，选择“开始接诊”；
2. 选择“故障图片”“故障视频”或“故障录音”，先接入现场材料；
3. 选择“检修资料”，先组织当前任务需要引用的案例、知识和手册；
4. 在“快速接诊”区域选择与现场现象一致的故障类型；
5. 从当前任务或最近记录中继续已经保存的业务。

快速接诊会预填相应的故障现象描述，工程师仍需检查并修改为实际现场事实。不能只根据故障类型名称直接确认设备原因。

### 6.2 现场异常接入

#### 6.2.1 填写异常描述

工程师应先记录看到、听到、测量到和系统告警反映的事实，再由后续诊断判断原因。

操作步骤如下：

1. 在工作台找到“现场接诊”区域；
2. 在“描述现场现象”输入框填写异常；
3. 建议按“设备位置＋设备对象＋现象＋告警或测量结果”的顺序描述；
4. 检查描述中是否包含未经确认的推断；
5. 根据需要继续接入材料和检修资料；
6. 选择“开始接诊”。

推荐描述示例：

> 站控柜内工控机出现温度告警，能够听到风扇声音异常，监控显示风扇转速偏低。

不建议只填写“设备坏了”“风扇故障”等过于简短或直接下结论的内容。描述越清楚，后续设备识别、资料匹配和诊断建议越准确。

> 【插图位置：图6-2 现场接诊与异常描述】
> 建议截图展示“描述现场现象”输入框、“开始接诊”按钮和现场采集入口，输入内容使用不含敏感信息的典型异常。

#### 6.2.2 使用语音输入

首页异常描述支持短时语音输入。语音输入只负责将用户说话识别为可编辑文字，不会未经确认直接提交异常。

操作步骤如下：

1. 在异常描述输入区域选择麦克风按钮；
2. 浏览器首次询问麦克风权限时，确认当前终端和环境允许使用后选择授权；
3. 麦克风状态变为“录音中”后，清楚说出现场异常；
4. 说完后选择停止录音；
5. 等待状态由“识别中”变为“识别完成”；
6. 检查回填到输入框中的文字；
7. 修正设备名称、型号、数字、单位和专业术语；
8. 确认文字准确后继续接诊。

录音过程中应尽量避免多人同时说话和持续强噪声。若浏览器拒绝授权、没有检测到录音设备、音频为空或识别失败，页面会保留文字输入方式，工程师可以直接使用键盘填写。

短时语音输入在识别完成、取消或失败后按语音输入规则清理。若需要保存设备异响或现场语音作为检修证据，应使用“故障录音”材料入口，而不是语音输入入口。

> 建议组合展示待机、录音中、识别中和识别完成四种状态，截图中不保留真实现场语音内容。

#### 6.2.3 接入图片材料

图片材料适合记录设备铭牌、面板灯态、告警画面、接线、滤网积尘、部件外观和安装环境。

操作步骤如下：

1. 在“现场采集”区域选择“故障图片”；
2. 从本地文件中选择一张或多张相关图片；
3. 等待图片缩略图出现在“现场证据”区域；
4. 选择缩略图放大预览，检查方向、清晰度和内容；
5. 删除误选、重复或与本次任务无关的图片；
6. 保留能够说明现场事实的图片并继续接诊。

涉及接线拆卸时，应在操作前拍摄能够辨认接口位置、线缆方向和标识的照片。图片中包含无关人员、账号、网络地址或其他敏感信息时，应按照现场管理要求处理后再上传。

#### 6.2.4 接入视频材料

视频材料适合记录间歇性告警、风扇启停、画面抖动、设备启动过程、指示灯变化和现场环境。

操作步骤如下：

1. 选择“故障视频”；
2. 从本地文件中选择与异常有关的视频；
3. 等待页面显示材料名称和缩略信息；
4. 打开预览，检查视频能否播放以及关键现象是否可见；
5. 删除无法读取、内容错误或无关的视频；
6. 确认保留的视频进入当前任务材料集合。

视频应尽量聚焦异常发生过程，避免上传与任务无关的长时间录像。上传较大视频时，应等待处理完成，不要在按钮处于处理中时重复选择同一文件。

#### 6.2.5 接入音频材料

音频材料适合记录风扇异响、蜂鸣器声音、机械振动声和现场人员对现象的补充说明。

操作步骤如下：

1. 选择“故障录音”或材料区域中的“添加音频”；
2. 选择已经保存的音频文件；
3. 等待页面显示音频材料；
4. 播放或预览音频，确认声音清晰且属于当前异常；
5. 删除误选或无法辨认的音频；
6. 保留需要随任务持续保存的音频证据。

音频材料会作为现场材料随任务保存，与只用于文字识别的短时语音输入不同。工程师应根据用途选择正确入口。

#### 6.2.6 预览和删除材料

已选择的图片、视频和音频集中显示在“现场证据”或“现场材料”区域。工程师可以选择材料卡片进行预览，也可以在提交前删除不需要的内容。

预览时重点检查：

- 文件是否能够正常打开；
- 材料是否属于当前设备和本次异常；
- 图片或视频中的关键位置是否清楚；
- 音频中的异常声音是否可辨认；
- 文件是否存在重复、错误或敏感内容；
- 材料数量和类型是否与页面汇总一致。

异常事件确认前删除材料，材料不进入正式任务。已经随任务确认或进入归档记录的材料受业务记录保护，不能通过普通删除操作破坏历史证据。

#### 6.2.7 保存异常信息

选择“开始接诊”后，系统进入分项确认流程。页面依次引导工程师确认发生时间、发生地点、设备与告警对象、其他现象和判断依据。每一项确认后，已知信息会持续显示在页面中。

工程师应在每一步选择对应的确认按钮。系统显示“正在生成下一项”时，应等待下一项出现，不要连续点击。需要修改已确认内容时，可以选择“已知信息”中的相应项目或页面上的“修改”入口返回。

异常信息完成分项确认后，系统形成“现场异常事件全景”。该页面汇总异常描述、时间、地点、设备、告警、运行参数、现场材料和检修资料。只有核对无误后，才能启动智能诊断。

### 6.3 检修资料选择

#### 6.3.1 打开检修资料选择器

工程师可以在工作台“现场采集”区域选择“检修资料”，打开“检修资料编组台”。已经选择的资料会形成“本次接诊资料包”，并持续用于异常确认、辅助诊断和后续检修。

资料编组台主要包含：

- 当前接诊建议；
- 全部资料、历史案例、检修知识和厂商手册分类；
- 关键词搜索；
- 可选资料卡片；
- 本次接诊资料包；
- 案例、知识和手册数量统计；
- 清空和确认按钮。

> 【插图位置：图6-5 检修资料编组台】
> 建议截图展示资料分类、搜索框、资料卡片、推荐资料和右侧“本次接诊资料包”。

#### 6.3.2 查看推荐资料

资料编组台根据当前设备、故障描述和告警方向显示推荐资料。工程师可以逐项查看推荐内容，也可以选择“采用推荐资料”将推荐内容加入当前资料包。

推荐资料只表示与当前信息具有较高相关性。工程师仍需核对：

- 资料类型是否满足本次需要；
- 适用设备是否与目标设备一致；
- 故障领域是否与现场现象一致；
- 厂商、型号、版本和发布日期是否适用；
- 案例的设备环境和处理条件是否可参考。

#### 6.3.3 按设备和故障筛选

工程师可以使用资料类型标签和搜索框缩小资料范围：

1. 选择“全部资料”“历史案例”“检修知识”或“厂商手册”；
2. 在搜索框输入故障、设备、资料标题或资料编号；
3. 查看符合条件的资料卡片；
4. 如果没有匹配结果，清除关键词或选择“查看全部资料”；
5. 根据适用范围继续选择资料。

搜索关键词可以使用设备类型、品牌型号、部件、故障现象或资料编号。过长或包含多个无关条件的关键词可能降低匹配效果，可拆分为设备和故障关键词分别查询。

#### 6.3.4 查看案例、知识和手册

三类资料具有不同用途：

| 资料类型 | 主要内容 | 使用方式 |
| --- | --- | --- |
| 历史案例 | 过去检修中的现象、原因、处理和恢复结果 | 对照相似故障和现场条件 |
| 检修知识 | 结构化的现象、原因、检查、措施和验证要求 | 形成诊断依据和步骤建议 |
| 厂商手册 | 设备结构、接口、安装、维护和参数说明 | 核对型号专用操作和原始资料 |

资料卡片显示资料编号、标题、摘要、设备或故障信息和标签。工程师选择资料前，应阅读摘要和适用范围。涉及接线顺序、端子位置、拆装方式、备件编号和固定阈值时，应优先使用目标型号厂商手册。

#### 6.3.5 选择或取消检修资料

选择资料卡片后，该资料进入右侧“本次接诊资料包”，资料卡片显示已选择状态。再次选择同一资料或点击资料包中的移除按钮，可以取消选择。

工程师可以同时选择多份资料，但应避免加入大量无关内容。资料包应尽量包含：

- 与设备型号匹配的厂商手册；
- 与主要故障现象相关的检修知识；
- 一至数个现场条件相近的历史案例；
- 与安全操作和恢复验证有关的必要资料。

选择“清空”会移除当前资料包中的全部资料。执行前应确认是否确实需要重新编组。

#### 6.3.6 查看已选资料包

完成选择后，选择“确认并用于本次接诊”。资料编组台关闭，工作台显示已选资料数量以及案例、知识和手册的组成。

已选资料包会在后续页面作为“检修资料”或“本次接诊资料包”持续显示。工程师可以再次打开资料编组台增加、取消或替换资料。最终诊断和步骤说明中实际使用的内容会显示对应资料来源。

### 6.4 设备与故障信息确认

#### 6.4.1 确认发生时间和地点

异常接入第1项用于确认异常时间。工程师需要填写或核对：

- 首次发现时间；
- 持续时长；
- 首次发现、间歇出现或重复发生等频次；
- 初始异常描述。

确认无误后选择“确认发生时间”。系统随后展示场站空间位置和识别到的故障点。工程师核对场站、区域、机柜和设备位置后选择“确认发生地点”。

如果异常发生时间只是估计值，应在描述或后续记录中说明。不得为了完成表单而填写明显不符合现场事实的时间。

> 建议采用两张连续页面截图，展示时间字段、异常描述、场站位置图和“确认发生地点”按钮。

#### 6.4.2 确认设备类型、品牌和型号

异常接入第3项用于确认发生事件与设备对象。页面显示系统根据现场描述、设备台账和检修知识形成的推荐信息，主要包括：

- 设备型号；
- 设备角色；
- 关联告警；
- 字段信息来源；
- 设备识别过程。

工程师可以选择“自动识别”获取系统建议，也可以直接从字段中选择正确内容。自动识别完成后，仍需对照设备铭牌、台账和现场位置核对结果。确认正确后选择“确认发生事件”。

系统识别到的设备与现场不一致时，应修改为正确设备。不同型号的接口、接线、部件和参数可能不同，不能为了沿用已有案例而选择错误型号。

#### 6.4.3 确认告警和运行参数

异常接入第4项用于补充其他现象和运行状态。根据设备与故障方向，页面显示相应的告警和参数字段，例如：

- 指示灯或告警状态；
- 蜂鸣器或设备声音；
- 风扇转速；
- 系统温度和CPU温度；
- 电压、存储健康或通信状态；
- 当前现场材料数量。

工程师应优先填写现场实际读取或测量的数值。页面提供建议值时，可以选择“采用建议”，但采用前必须确认建议的适用设备、单位和现场条件。无法获取的参数不应编造，可按页面规则标记未记录并在后续补充。

确认参数和材料后，选择“确认其他现象”。

#### 6.4.4 修改系统推荐信息

系统推荐值来自现场描述、设备台账、告警规则和检修知识。工程师可以修改任何允许人工确认的推荐内容。

修改方法如下：

1. 在当前步骤直接修改字段；
2. 对已经确认的内容，选择“已知信息”中的时间、地点、设备或其他现象；
3. 在汇总页选择对应的“修改”按钮；
4. 完成修改后重新确认该项；
5. 检查后续推荐和诊断方向是否随之更新。

修改设备型号、关联告警或关键参数可能改变后续诊断分支。系统提示当前知识不足或需要补充专用案例时，工程师应补充资料或转由专家协助，不应强行使用不匹配的故障流程。

#### 6.4.5 查看现场信息摘要

五项信息确认完成后，系统生成“现场异常事件全景”，汇总：

1. 异常描述、发生时间和持续情况；
2. 场站、区域和设备位置；
3. 设备型号、设备角色和关联告警；
4. 图片、视频和音频材料数量；
5. 告警和运行参数；
6. 判断依据和操作手册；
7. 本次接诊资料包；
8. 即将启动的诊断方向。

工程师应逐项核对。发现错误时，使用页面上的“修改时间”“修改地点”“修改设备”“修改”或“重新核对”等入口返回。全部正确后选择“确认并启动智能诊断”。

### 6.5 智能辅助诊断

#### 6.5.1 启动辅助诊断

在“现场异常事件全景”页面确认信息后，选择“确认并启动智能诊断”。系统将已确认的设备、异常、材料、运行参数和检修资料组织为诊断输入。

启动前应满足以下条件：

- 现场异常描述已经确认；
- 发生时间和地点已经确认；
- 设备与告警对象已经确认；
- 必要运行状态已经填写；
- 现场材料可以正常读取；
- 检修资料包已经核对；
- 当前故障方向具有可使用的检修知识。

按钮显示“正在启动诊断”时，系统正在建立诊断任务。工程师应等待状态更新，不要重复提交。

#### 6.5.2 查看分析过程

辅助诊断通常分为以下阶段：

1. **触发诊断：** 接收异常接入信息并确定诊断边界；
2. **分析诊断：** 分析现场现象和运行参数，形成可能故障方向；
3. **操作合规检查：** 核对断电、挂牌、冷却和防静电等要求；
4. **知识检索：** 查找相关案例、知识条目和设备手册；
5. **形成结论：** 汇总可能原因、风险和建议处理方向。

页面显示当前步骤、已完成分析项、主要知识依据和处理状态。分析时间较长时，工程师可以观察进度，但不应把中间状态当作最终诊断结论。

> 建议截图展示诊断阶段、分析状态、知识依据和已完成标识。

#### 6.5.3 查看故障方向和判断理由

诊断完成后，页面展示：

- 诊断标题和异常摘要；
- 主要故障方向；
- 可能原因排序；
- 每项原因的判断说明；
- 继续检查的重点；
- 建议进入检修方案的提示。

可能原因会根据现场现象和资料依据区分优先级。工程师应结合现场条件判断，而不能只选择排序第一的原因。例如，风扇低速、滤网积尘和机柜通风异常可能同时存在，需要通过后续检查逐项确认。

#### 6.5.4 查看知识依据和安全提示

诊断页面中的资料卡片或依据区域展示本次分析引用的案例、知识条目、手册章节、告警规则和安全要求。工程师查看依据时，应注意：

- 资料名称和编号；
- 资料类型和来源；
- 适用设备、型号和故障领域；
- 引用的判断条件或操作要求；
- 内容是否为已发布版本；
- 是否存在需要现场复核的不确定项。

安全提示属于检修前置条件。涉及断电、拆装和恢复上电时，工程师必须同时核对现场制度和目标设备手册。

#### 6.5.5 使用文字追问

工程师可以在检修智能体输入区对诊断结论和资料依据进行追问，例如：

- 为什么优先判断为散热异常；
- 当前告警可能对应哪些部件；
- 还缺少哪些现场参数；
- 目标设备需要核对哪些手册章节；
- 哪些安全条件必须先完成。

输入问题后选择发送，系统结合当前任务和检修资料回答。回答中提供资料来源时，可打开来源卡片进一步核对。诊断追问用于解释和补充信息，不会自动确认诊断或完成检修步骤。

#### 6.5.6 使用语音追问

诊断追问支持语音输入，操作方式与异常描述语音输入一致：

1. 选择检修智能体输入区的麦克风按钮；
2. 启动录音并清楚说出问题；
3. 停止录音并等待识别；
4. 检查回填的文字；
5. 修改设备名、部件名、数值或单位；
6. 确认后发送问题。

语音识别内容未经用户确认不会直接发送。识别失败时可以重新录制或改用键盘输入。

#### 6.5.7 确认诊断结论

工程师确认诊断结果前，应完成以下检查：

- 诊断使用的设备对象正确；
- 现场事实和参数没有遗漏或错误；
- 可能原因与现场现象基本一致；
- 主要资料来源能够打开并适用于目标设备；
- 安全风险和前置条件已经理解；
- 信息不足项已经补充或明确记录。

确认后进入检修预方案阶段。若发现现场信息有误，应返回异常接入修改；若资料不足，应补充检修资料或请求专家支持。

### 6.6 检修预方案

#### 6.6.1 查看预方案

在诊断结论页面选择“生成检修预方案”后，系统根据诊断结果、知识依据和安全要求生成两级检修大纲。页面显示检修阶段数量、小维修步骤数量、工程师修改数量和强制安全项数量。

预方案生成过程中，页面显示“正在生成步骤提纲”。全部阶段显示后，状态变为“等待工程师确认”。工程师应先通读完整方案，再决定直接采用或修改。

#### 6.6.2 查看检修阶段和步骤

每个检修阶段通常包含：

- 阶段序号和标题；
- 阶段检修目标；
- 一条或多条小维修步骤；
- 步骤来源；
- 安全要求；
- 判断条件或阈值；
- 系统生成或工程师修改标识。

工程师应检查阶段顺序是否符合现场操作条件，小维修步骤是否覆盖必要检查，资料依据是否适用于目标设备，以及强制安全项是否位于危险操作之前。

#### 6.6.3 修改步骤内容

工程师可以直接修改阶段标题、阶段目标和普通小维修步骤文字。修改时应：

1. 选择需要修改的文本框；
2. 根据现场条件填写清楚的动作和检查对象；
3. 保留必要的设备、位置、参数和结果要求；
4. 离开文本框后查看“工程师修改”数量是否更新；
5. 检查修改后的步骤是否仍然可以执行和验证。

修改内容会作为方案修订保留。不能使用含义模糊的“处理一下”“检查正常”等表述，应说明检查对象、动作和完成条件。

#### 6.6.4 新增、删除和调整步骤

工程师可以根据现场条件执行以下操作：

- 选择“新增检修阶段”增加一个阶段；
- 选择“添加小维修步骤”在当前阶段增加检查项；
- 使用上移或下移按钮调整阶段顺序；
- 使用上移或下移按钮调整小维修步骤顺序；
- 删除不适用的普通阶段或普通小维修步骤；
- 选择“恢复系统初稿”撤销当前修改并恢复原方案。

每个检修阶段至少保留一条有效的小维修步骤，整个方案至少保留一个阶段。删除或恢复操作前，应确认是否需要保留已填写内容。

#### 6.6.5 强制安全步骤说明

正常关机、拔除所有电源、等待冷却和防静电等内容属于强制安全项。页面使用安全标识显示，删除按钮不可用。包含强制安全项的阶段不能整体删除。

强制安全项用于保证后续拆检具备必要条件。工程师可以根据现场制度补充更严格的要求，但不能删除、弱化或安排在危险操作之后。涉及特殊设备和场站时，还应增加挂牌、隔离、监护和作业许可等现场要求。

#### 6.6.6 确认检修方案

确认方案前，工程师应检查：

1. 每个阶段都有明确标题和目标；
2. 每个阶段至少包含一条有效步骤；
3. 阶段和步骤顺序符合现场条件；
4. 强制安全步骤完整并位于危险操作之前；
5. 型号专用操作具有适用资料；
6. 测量值、单位和判断条件明确；
7. 方案能够覆盖诊断中的主要原因；
8. 不适用内容已经删除或修正。

确认无误后选择“确认方案并进入检修向导”。确认后的方案作为本次任务实际执行依据。需要继续核对诊断时，可以选择“返回诊断结论”。

### 6.7 标准化检修向导

#### 6.7.1 进入检修向导

检修预方案确认后，系统进入“检修向导”页面，并按照已确认的阶段和步骤顺序组织现场作业。页面主要由当前步骤说明、步骤进度、现场参考图、检查项、判断条件、安全要求、来源依据和操作按钮组成，右侧为检修智能体对话区。

> 建议截图展示当前步骤标题、步骤进度、参考图、检查项、阈值、安全要求、来源依据以及右侧检修智能体。

进入页面后，工程师应先确认以下内容：

- 当前设备和任务与现场作业对象一致；
- 当前步骤序号、标题和目标清楚；
- 前置步骤已经完成；
- 本步安全要求已经具备执行条件；
- 使用的手册、案例或知识条目适用于当前设备；
- 需要使用的工具、仪表和防护用品已经准备完毕。

检修向导用于辅助工程师规范执行和记录，不代替现场作业许可、停送电制度、人员监护和工程师最终判断。

#### 6.7.2 查看当前步骤

页面顶部显示“第 X / Y 步”、当前步骤标题和操作目的。参考图区域用于说明检查位置或操作对象；选择不同检查项时，参考图和文字提示可随检查对象切换。右侧信息区显示本步检查项、判断条件、安全要求和来源依据。

工程师应依次阅读：

1. 当前步骤说明，明确本步需要解决的问题；
2. 参考图和定位提示，确认检查对象及其所在位置；
3. 判断条件，了解正常范围、异常特征或完成标准；
4. 安全要求，确认是否需要断电、等待冷却、防静电或专人监护；
5. 来源依据，核对手册、案例或知识条目的适用范围。

若现场设备结构、接口标识或参数与页面提示不一致，应暂停当前操作，重新核对设备信息和适用资料，必要时请求专家支持。

#### 6.7.3 确认检查项

当前步骤包含一条或多条检查项。工程师完成一项现场检查后，选择对应检查项进行确认；页面同步更新已完成数量和本步确认进度。再次选择已确认项可以取消确认，以便修正误操作。

确认检查项表示工程师已经完成对应现场动作并核对结果，不表示系统自动完成了设备操作。不得在未执行、未观察或结果不明确的情况下提前确认。存在异常时，应先记录现场事实和处理结果，再决定继续、返回或发起专家会诊。

只有本步全部检查项均已确认后，“完成并继续”按钮才可使用。该限制用于避免遗漏必要检查，不应通过跳步规避。

#### 6.7.4 记录现场处理结果

工程师应在执行过程中记录能够支持最终结论的事实，包括：

- 检查对象的实际状态；
- 发现的积尘、松动、损坏、异响、过热、腐蚀或其他异常；
- 使用的工具、测量方法和测量值；
- 实际采取的清理、紧固、更换、复位或调整措施；
- 处理前后的告警、灯态、声音和运行参数变化；
- 无法完成的检查项及其原因；
- 仍需复核的风险和后续建议。

记录应采用“对象—现象—动作—结果”的方式描述。例如：“检查前面板滤网，发现积尘遮挡进风区域；完成清理并复装后，进风通道恢复通畅。”避免只填写“已处理”“正常”等无法追溯的结论。

#### 6.7.5 补充现场材料

检修过程中可以继续补充现场图片、视频和音频。材料应优先覆盖故障现象、关键拆检位置、异常部件、测量读数、处理动作和恢复结果。

补充材料时应注意：

1. 文件内容与当前设备和当前步骤直接相关；
2. 图片中的接口标识、线缆位置或仪表读数清晰可辨；
3. 视频能够反映异响、振动、启停或灯态变化；
4. 音频应尽量降低现场环境噪声；
5. 不上传包含账号口令、人员隐私或无关敏感信息的文件；
6. 危险区域内的拍摄和录音应遵守现场管理规定。

材料会随本次任务进入检修记录，供后续复核和专家审核使用。

#### 6.7.6 追问当前步骤

右侧“检修智能体”根据当前步骤提供上下文相关的问答支持。工程师可以在输入框中输入当前步骤遇到的问题，例如操作顺序、检查方法、异常原因、正常范围或安全注意事项，然后发送问题。

在“检查滤网、风扇和接线”步骤中，可以追问：

- “FAN1/FAN2 的接线顺序应该怎样核对？”
- “风扇转速偏低可能由哪些情况导致？”
- “滤网清理后还需要检查哪些位置？”

系统回答时会结合当前步骤、设备资料、检修知识和已填写的现场事实，并显示使用的知识依据。工程师应核对回答是否适用于目标设备。涉及接口定义、接线方向、拆装顺序和阈值时，以对应设备手册、接口标识和现场测量结果为准。

检修智能体只回答当前任务上下文内的问题。切换步骤后，对话上下文会随当前步骤更新。若问题超出当前步骤范围，应先切换到对应步骤或通过专家会诊处理。

#### 6.7.7 使用检修步骤语音播报

选择“语音播报”后，系统提取当前检修步骤，组织操作顺序和安全提示，并开始播报当前步骤内容。播报窗口显示生成状态、动态波形、取消按钮和完成按钮。

使用方法如下：

1. 确认页面停留在需要播报的检修步骤；
2. 选择“语音播报”；
3. 等待系统完成内容组织；
4. 收听当前步骤、操作顺序和安全提示；
5. 需要中止时选择取消按钮；
6. 播报结束后选择完成按钮关闭窗口。

语音播报适用于双手操作、远距离查看设备或需要复述安全要求的场景。现场环境嘈杂、涉及高风险操作或播报内容听辨不清时，应返回页面阅读原文，不得仅凭片段语音执行操作。

#### 6.7.8 请求专家支持

工程师在当前步骤遇到以下情况时，可以选择“专家视频会诊”：

- 设备结构或接口与资料不一致；
- 异常现象无法由当前检查项解释；
- 需要确认拆装、接线或带风险的处理方式；
- 关键参数持续异常，无法满足进入下一步的条件；
- 需要专家查看现场视频、图片或实时操作过程；
- 工程师判断继续操作可能扩大故障或产生安全风险。

发起会诊后，系统携带当前任务、设备、步骤、故障现象和已有材料进入专家协同界面。工程师应向专家说明已经完成的检查、实际测量结果、已采取的措施和当前阻塞点。专家意见应由工程师结合现场条件确认后执行。

#### 6.7.9 完成当前步骤

完成当前步骤前，应确认：

1. 所有检查项均已实际执行；
2. 异常现象和处理结果已经记录；
3. 需要的现场材料已经补充；
4. 测量值、单位和判断结果准确；
5. 本步安全要求持续满足；
6. 不存在必须在进入下一步前解决的风险。

全部检查项确认后，选择“完成并继续”。系统保存本步完成状态并生成下一步内容。需要重新核对上一阶段时，可以选择“上一步”；返回后应注意已拆装部件、供电状态和现场隔离条件是否发生变化。

#### 6.7.10 查看整体检修进度

页面通过步骤序号和本步确认进度显示检修进展。整体检修通常依次覆盖告警与设备确认、安全准备、环境与风道检查、滤网风扇及接线检查、恢复运行与验证等阶段。

工程师应按照向导顺序推进。只有最后一步完成后，才可以生成检修记录。若中途退出任务，再次进入时应先核对已完成步骤与现场实际状态，避免因设备状态变化直接沿用旧的确认结果。

### 6.8 恢复运行验证

#### 6.8.1 执行恢复前检查

完成清理、紧固、更换或调整后，进入“恢复运行与验证”步骤。恢复供电前，应至少确认：

- 工具、螺钉、线头和清洁材料已经移出设备内部；
- 滤网、风扇、挡板、机箱盖板和防护件安装到位；
- 电源线、风扇线、信号线及接地连接正确且牢固；
- 接口方向、线序和固定方式符合设备资料；
- 防静电操作已经结束，人员和设备处于安全位置；
- 现场隔离、挂牌和送电许可符合管理要求；
- 由有权限的人员确认可以恢复供电。

系统不会自动控制设备送电。恢复运行必须由现场有权限的人员按照制度执行。

#### 6.8.2 记录告警状态

恢复供电后，先观察设备启动过程、状态灯、蜂鸣器和监控告警。记录处理前后的告警名称、状态和变化时间，并重点确认：

- 原有告警是否解除；
- 是否出现新的告警或异常灯态；
- 蜂鸣器是否停止或出现新的声音提示；
- 设备启动过程是否完整；
- 业务数据和监控数据是否恢复。

告警暂时消失但再次出现时，不应直接判定恢复成功，应继续观察并重新检查对应原因。

#### 6.8.3 记录风扇转速与温度

按照页面提示填写恢复后的风扇转速、系统温度和 CPU 温度。填写时应保留明确单位，并与处理前数据进行对比。

典型散热异常任务中，页面会提示关注风扇转速是否恢复、系统温度和 CPU 温度是否下降，以及 TEMP/FAN 告警是否解除。页面中的判断条件用于辅助识别异常趋势，具体设备的正常范围以设备手册、固件监测口径、环境条件和现场标准为准。

若风扇仍然低速或停转，应检查供电、接口接触、线序、风扇本体、控制策略、转速反馈和风道阻力；若风扇转速恢复但温度仍高，应继续检查环境温度、进出风口、散热器接触、负载状态和其他发热部件。

#### 6.8.4 记录其他运行参数

除告警和温度外，应根据故障类型补充与恢复结论直接相关的运行参数。例如：

- 供电故障：输入电压、输出电压、电源状态和负载变化；
- 存储故障：硬盘状态、读写结果、启动状态和错误信息；
- 通信故障：链路状态、端口状态、通信恢复情况和数据连续性；
- 凝露或环境异常：环境温湿度、表面状态和持续观察结果；
- 监控告警故障：指示灯、蜂鸣器、告警复位和远程监控状态；
- 接口或外设故障：识别状态、连接稳定性和功能验证结果。

参数应注明采集时间、测量位置、单位和使用的仪表或系统来源，以便后续复核。

#### 6.8.5 填写观察时间和遗留风险

恢复运行后，应持续观察至设备状态稳定。系统提供“连续观察”记录项，工程师填写实际观察时长，并描述观察期间的告警、参数和业务运行情况。

“遗留风险”应填写尚未完全排除的问题，例如部件老化、环境条件未根治、临时替换件、参数波动、需要停机复查或等待备件等。无已知遗留风险时，也应填写“未发现已知遗留风险”，不能留空。

观察时间应结合故障性质、设备启动周期、负载变化和现场制度确定。短时参数恢复不等于故障已经稳定消除。

#### 6.8.6 确认恢复结论

恢复验证结论可概括为“恢复正常”“带风险恢复”或“未恢复”。确认前应检查：

1. 原故障现象是否消失；
2. 告警、灯态和声音是否恢复正常；
3. 关键运行参数是否达到设备要求；
4. 业务功能和数据通信是否稳定；
5. 连续观察时间是否满足要求；
6. 遗留风险是否已经记录并安排后续措施。

未达到恢复条件时，不得填写为“恢复正常”。应保留故障状态，返回相关检修步骤、请求专家支持或按现场制度升级处理。

### 6.9 检修记录

#### 6.9.1 自动生成检修记录

完成检修向导最后一步后，选择“生成检修记录”。系统汇总异常接入信息、诊断结论、检修方案、已完成步骤、工程师确认结果、恢复验证参数和现场材料，形成结构化检修记录。

检修记录页面按“事实与判断—工程师确认—恢复验证—执行轨迹—现场证据—来源追溯”组织内容，便于工程师检查故障从发现到恢复的完整链路。

- 遗留风险。

系统可以根据现场任务提供建议内容，工程师必须逐项核对后确认。记录一经提交专家审核，关键字段进入受控状态；需要更正时，应按审核流程退回或形成补充说明。

#### 6.9.3 查看检修记录详情

从左侧导航进入“检修记录”，可以查看记录台账。记录列表显示记录标题、发生时间、故障类型、设备型号、检修人员和当前状态。选择任一记录后，进入该记录详情页。

详情页通常包含：

- 设备、场站、机柜和发生时间；
- 故障现象、告警和诊断结论；
- 最终故障原因和实际处理；
- 处理前后参数对比；
- 已完成检修步骤和安全确认；
- 现场图片、视频和音频；
- 记录来源、关联案例和关联知识；
- 专家审核及知识回流状态。

#### 6.9.4 搜索历史检修记录

在记录台账的搜索框中输入设备型号、故障名称或关键词，系统筛选匹配记录。例如可以输入“供电”“风扇”“存储”或某一设备型号。

搜索无结果时，应检查关键词是否过于具体、型号写法是否一致，或清空搜索条件重新查看全部记录。历史记录用于提供相似故障参考，不能替代对当前设备和当前现场事实的确认。

#### 6.9.5 查看记录状态

检修记录根据闭环进度显示不同状态：

- **尚未上传**：记录已生成，等待工程师确认；
- **待专家审核**：工程师已提交，等待专家复核；
- **已审核并发布知识**：专家审核完成，相关内容已进入正式知识；
- **已归档**：记录闭环完成并作为历史台账保存。

状态用于说明记录当前所处环节。工程师提交的案例不会直接修改正式知识库或知识图谱，必须经过专家审核和发布。

#### 6.9.6 提交专家审核

工程师完成记录核对后，选择提交专家审核。提交前应确认必填字段完整、恢复参数真实、现场材料可用、遗留风险明确，并检查设备和故障分类是否正确。

提交成功后，页面显示案例编号和待审核状态。专家可以基于该记录修订案例内容、提炼知识条目并更新知识图谱。若上传失败，系统保留当前表单内容，工程师可根据提示检查连接或文件状态后重试。

### 6.10 检修作业卡

#### 6.10.1 生成检修作业卡

检修作业卡以工程师确认后的检修记录为数据来源。进入记录详情页并完成必填内容后，选择“打印作业卡”，系统生成适合 A4 纸张的两页作业卡。

作业卡强调检修结论、处理前后参数和执行摘要，不重复展开全部向导操作说明。详细操作方法和安全要求仍以检修向导及对应设备手册为准。

#### 6.10.2 查看作业卡内容

作业卡第一页主要包含：

- 产品名称、记录编号和闭环状态；
- 本次检修结论摘要；
- 设备、场站、位置、时间、人员和班组；
- 故障现象、最终原因、实际处理和恢复结果；
- 处理前后关键参数对比。

第二页主要包含：

- 已完成检修步骤；
- 现场证据摘要；
- 遗留风险和后续建议；
- 来源记录、关联案例和关联知识；
- 检修人员、复核人员和审核日期签字区。

#### 6.10.3 打印作业卡

选择“打印作业卡”后，浏览器打开打印窗口。打印前应完成以下设置：

1. 选择正确的打印机；
2. 纸张选择 A4；
3. 方向选择纵向；
4. 缩放使用默认比例或适合页面；
5. 检查页数为两页；
6. 预览标题、表格、页脚和签字区是否完整；
7. 根据归档要求选择单面或双面打印。

若出现内容截断，应检查浏览器缩放、纸张尺寸和打印边距，不要直接缩小到难以阅读的比例。

#### 6.10.4 导出 PDF 文件

在打印窗口中选择“另存为 PDF”或系统提供的 PDF 打印设备，确认文件名和保存位置后导出。默认文件名包含“工控机故障检修作业卡”、记录编号和日期，便于归档与检索。

导出后应打开 PDF 检查：

- 文件能够正常打开；
- 总页数和页面顺序正确；
- 中文、数字、单位和符号显示完整；
- 表格无跨页错位或内容遮挡；
- 记录编号、日期和页码正确；
- 敏感信息符合交付和归档要求。

### 6.11 工程师知识图谱

#### 6.11.1 打开知识图谱

在工程师端左侧导航选择“知识图谱”，进入“工控机知识图谱”页面。页面由视图切换区、知识版本状态、统计信息、图谱画布、操作工具栏、图例和节点详情区组成。

页面提供两个主要视图：

- **全局知识图谱**：查看设备、故障领域、故障现象、原因、部件、检查方法、处置措施、知识条目和案例之间的整体关系；
- **本次新增与修改**：突出当前案例或知识发布形成的新增节点、修改节点和新增关系。

> 【插图位置：图6-14 工程师知识图谱页面】
> 建议截图展示“全局知识图谱 / 本次新增与修改”切换、知识版本状态、图谱统计、画布、图例和节点详情区。

#### 6.11.2 查看知识版本状态

页面顶部显示本地知识版本和最新发布版本。当专家发布了新知识而工程师端尚未更新时，系统提示发现新版本；工程师可以先查看图谱变化，再按权限执行同步。

同步完成后，页面显示本地版本已更新并参与诊断。版本状态用于说明当前检索、问答和诊断所使用的知识范围。发现版本不一致时，应先确认网络和更新内容，不在关键检修过程中盲目切换知识版本。

#### 6.11.3 缩放和平移图谱

图谱画布支持以下操作：

- 滚动鼠标滚轮缩放；
- 按住画布拖拽进行平移；
- 选择“放大”或“缩小”按钮调整比例；
- 查看工具栏中的当前缩放百分比；
- 选择“返回全局”恢复默认视角。

缩放时应先将目标区域移动到画布中央。图谱内容较密集时，可以先使用搜索定位，再放大查看局部关系。

#### 6.11.4 搜索、选择和聚焦节点

在“搜索节点或领域”输入框中输入设备、故障、部件或知识名称，选择“定位”，系统将镜头移动到匹配节点。选择画布中的节点后，镜头自动聚焦该节点及其一跳关系，其他无关节点弱化显示。

需要取消聚焦时，可以选择画布空白区域或“返回全局”。搜索没有结果时，可缩短关键词，改用故障领域、部件名称或现象名称重新搜索。

#### 6.11.5 查看节点及关联关系

选择节点后，右侧详情区显示节点名称、类型、所属领域、说明、知识状态、来源和关联关系。画布同时突出与该节点直接相连的节点及关系方向。

工程师可以利用关联关系完成以下查看：

- 从故障现象追溯可能原因；
- 从故障原因查看关联部件和检查方法；
- 从处置措施查看适用知识和安全要求；
- 从知识条目查看来源手册和案例；
- 从案例查看形成的节点及关系变更。

图谱关系用于组织和检索知识，不代表所有关联均适用于当前设备。工程师仍需结合设备型号、现场事实和资料适用范围进行判断。

#### 6.11.6 查看本次新增与修改

切换到“本次新增与修改”后，页面弱化未变化内容，突出新增或修改的节点与关系，并显示本次变更数量。该视图用于理解工程师提交的现场记录经过专家审核后，如何形成新的案例、知识和图谱关系。

工程师可以依次选择突出显示的节点，查看变更类型、来源案例、专家审核状态和关联知识。正式发布前的候选变更不参与工程师端正式诊断；专家发布并完成版本同步后，相关内容才进入正式知识范围。

### 6.12 工程师个人设置

#### 6.12.1 查看和修改账号资料

在左侧导航选择“设置”，进入“日常使用设置”页面。账号资料区域显示姓名和当前身份。工程师可以修改显示姓名，并核对当前身份是否为“一线检修人员”。

姓名会用于顶部栏、检修记录和作业卡。修改后应选择“保存设置”，并确认页面显示“已保存”。身份变更涉及权限范围时，应由管理员按照账号管理制度处理。

#### 6.12.2 设置场站、班组和设备范围

“场站与班组”区域用于维护所属场站和班组；“默认设备范围”用于设置进入诊断入口时优先使用的设备范围。可根据实际职责选择单个站控柜、站控柜内全部工控设备或当前场站全部设备。

默认范围只影响页面初始选择，不限制工程师在授权范围内核对其他设备。变更场站或班组后，应检查检修记录中的责任信息是否正确。

#### 6.12.3 设置通知方式

在“通知与语音”区域设置告警通知偏好，可选择仅接收高优先级告警、接收全部告警或关闭通知。现场值守岗位应根据岗位职责和告警制度设置，不建议在需要持续监视设备状态时关闭必要告警。

#### 6.12.4 设置语音播报偏好

语音播报可以设置为仅播报检修步骤、播报诊断结论与检修步骤，或关闭语音播报。设置保存后，在后续任务中按照所选偏好提供语音辅助。

语音功能不能替代页面原文、安全规程和现场口头确认。公共区域使用时应注意音量、信息保密和对其他作业的影响。

#### 6.12.5 设置作业卡与专家协同偏好

在“作业卡与专家协同”区域设置默认输出格式和专家协同方式。作业卡可按归档要求选择 PDF、文档或打印版记录；专家协同可设置为异常结论后、检修完成后或人工需要时提交。

默认偏好不会绕过工程师确认和专家审核。检修记录必须由工程师核对后提交，候选知识必须由专家审核后发布。

#### 6.12.6 设置流程确认选项

“流程确认”区域提供以下选项：

- **检修向导中始终显示安全确认**：在每个相关步骤保留安全要求和确认提示；
- **检修完成后自动生成记录**：最后一步完成后生成检修记录，供工程师继续完善和确认。

建议保持安全确认开启。即使关闭一般提示，强制安全步骤仍受流程约束，工程师也必须遵守现场安全制度。

#### 6.12.7 保存设置

完成修改后选择页面右上角“保存设置”。保存成功后，账号资料区域显示“已保存”。若离开页面后设置未生效，应重新进入设置页检查内容，并确认当前账号具备修改权限。

## 7. 专家端使用说明

### 7.1 专家工作台

#### 7.1.1 进入专家工作台

专家使用具有审核权限的账号登录后，系统进入“专家工作台”。专家端用于复核工程师提交的检修案例、修正专业结论、提炼结构化知识、确认知识图谱关系并发布正式知识。

专家端左侧导航主要包含：

- 专家工作台；
- 全部案例；
- 检修知识库；
- 知识图谱；
- 专家设置。

页面顶部显示当前账号和知识版本状态。专家开展审核前，应核对登录身份、专业范围和当前待办是否正确。

> 建议截图展示专家端导航、案例统计、待审核案例、当前知识版本和最近归档案例。

#### 7.1.2 查看工作台统计

工作台统计区域显示全部案例、待专家审核、已归档案例和知识条目数量。统计数据用于帮助专家了解当前任务负荷和知识沉淀情况。

当待审核数量大于零时，专家应优先处理影响现场运行、安全风险较高或长期未处理的案例。统计数量与列表不一致时，可以刷新页面，并检查当前筛选条件和账号权限。

#### 7.1.3 查看当前待审核案例

“当前完整案例”区域显示案例标题、设备、场站、提交工程师、目标知识和当前状态，并通过“工程师确认—专家审核—知识发布”展示案例所处环节。

案例处于“待专家审核”时，选择“进入专家审核”打开三步审核流程。若案例仍等待工程师确认，专家不能直接替代工程师填写现场结果；应由工程师完成确认和提交后再进入审核。

#### 7.1.4 查看最近归档案例

“最近归档案例”区域显示近期完成审核的案例摘要。选择案例后可以查看故障类型、设备、场站、最终原因、处理方法、恢复结果和关联知识。

历史案例用于辅助判断相似问题，专家不能仅因现象相似而直接复用结论。应核对设备型号、硬件版本、环境条件、告警信息和现场证据。

#### 7.1.5 识别案例状态

专家端常见案例状态如下：

| 状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 待工程师确认 | 现场结果尚未由工程师确认 | 等待工程师完善并提交 |
| 待专家审核 | 工程师已提交完整案例 | 进入专家审核流程 |
| 已通过并沉淀知识 | 案例已审核，知识已发布 | 查看知识结果或验证应用 |
| 已归档 | 案例已完成闭环 | 作为历史案例查阅 |
| 资料收集中 | 当前证据不足，尚未形成完整结论 | 补充资料后再复核 |

### 7.2 专家案例审核

#### 7.2.1 进入审核流程

从专家工作台选择待审核案例，进入专家审核页面。审核流程分为三个步骤：

1. 审核并修正案例；
2. 修正知识与知识图谱；
3. 确认并发布。

页面顶部显示案例编号、案例标题和当前审核步骤；右侧“案例速览”显示场站、位置、设备、发生时间、工程师、告警和恢复参数。专家可以随时查看当前审核上下文。

#### 7.2.2 核对工程师上传证据

第一步左侧为“工程师上传证据”，内容只读，主要包括：

- 来源检修记录；
- 异常描述；
- 告警与运行参数；
- 智能辅助诊断结论；
- 已完成检修步骤；
- 恢复验证参数；
- 现场图片、视频和音频摘要。

专家不能直接修改工程师确认的现场事实。发现证据错误、内容缺失或相互矛盾时，应选择“退回补充”，说明需要工程师重新确认的具体字段。不能通过修改专家结论掩盖原始证据问题。

核对证据时应重点检查：

1. 设备、场站、机柜和发生时间是否一致；
2. 故障现象与告警、参数是否相互支持；
3. 检修步骤是否覆盖主要故障方向；
4. 处理动作与恢复结果之间是否存在合理关系；
5. 恢复参数、观察时间和遗留风险是否完整；
6. 现场材料是否能够支持关键判断；
7. 所用资料是否适用于目标设备和硬件版本。

#### 7.2.3 选择审核决定

专家可以选择以下审核决定：

- **修正后通过**：现场证据完整，专业结论经过修正后可以形成正式案例和知识；
- **退回补充**：证据不足、字段冲突或恢复验证不完整，需要工程师补充；
- **仅归档案例**：案例具备记录价值，但证据或普适性不足，不适合沉淀为可复用知识。

选择审核决定后，应继续填写与决定相符的审核结论。选择“退回补充”时，应明确说明补充对象、补充原因和完成条件；选择“仅归档案例”时，应说明不形成正式知识的原因。

#### 7.2.4 修正案例结论

第一步右侧为专家可编辑区域，主要包括：

- 最终故障原因；
- 实际处理；
- 恢复结果；
- 知识沉淀价值。

专家可以在不改变现场事实的前提下，修正专业表述、因果关系和适用范围。例如，将含义宽泛的“风扇问题”修正为能够被证据支持的具体原因，并将实际处理写成可复核的动作和结果。

“知识沉淀价值”用于说明该案例能够为后续检修提供什么新增判断、检查方法、处置条件或适用边界。没有新增价值的案例可以归档，但不必强行形成新知识。

#### 7.2.5 保存审核草稿

审核过程中可以选择“保存草稿”。系统保存当前审核决定、案例修订、结构化知识、图谱关系和当前步骤。再次进入该案例时，可以从已保存位置继续处理。

建议在以下时机保存草稿：

- 完成案例结论修订后；
- 完成一组知识字段后；
- 修改多条图谱关系后；
- 需要离开页面查阅手册或与其他专家讨论前；
- 发布前进行最终复核时。

保存草稿不会发布知识，也不会改变工程师端当前使用的正式知识版本。

#### 7.2.6 确认案例并进入知识提炼

完成第一步后，检查审核决定、最终原因、实际处理、恢复结果和知识沉淀价值均已填写，再选择“确认案例并提炼知识”。

如果必填字段不完整，系统不允许进入下一步。需要重新核对现场证据时，可以保留草稿并停留在当前步骤。

### 7.3 结构化知识修订

#### 7.3.1 查看知识结构

审核流程第二步用于把案例经验整理成可检索、可复用和可追溯的结构化知识。知识字段主要包括：

- 适用设备；
- 异常现象；
- 判断条件；
- 可能原因；
- 检查顺序；
- 处理方法；
- 安全要求；
- 恢复标准；
- 不适用范围。

> 【插图位置：图7-3 结构化知识与图谱关系修订】
> 建议截图展示结构化知识字段、关系编辑区、新增关系按钮和图谱预览。

每个字段应采用简洁、明确且可以执行或验证的表述。知识条目不应只记录单次案例的叙述，而应提炼其中能够在适用范围内复用的判断方法。

#### 7.3.2 填写适用设备和异常现象

“适用设备”应说明品牌、系列、结构范围或通用设备类别。知识只适用于指定型号时，应明确限制；属于同系列参考或跨品牌通用机理时，也应注明使用边界。

“异常现象”应描述工程师可以观察或测量的事实，例如告警名称、灯态、声音、转速、温度、通信状态、供电状态或存储错误。不要把未经确认的原因写入异常现象。

#### 7.3.3 填写判断条件和可能原因

“判断条件”用于说明在什么证据组合下可以提高某一原因的优先级，应包含必要的前置检查、测量值、变化趋势或排除条件。

“可能原因”应与现场证据和设备机理一致。一个现象可能对应多个原因，专家应说明原因之间的优先级或区分方法，避免把相关性直接写成确定因果关系。

涉及具体阈值时，应注明单位、采集位置、适用型号、环境条件和资料来源。缺少可靠依据的数值不应作为通用标准发布。

#### 7.3.4 填写检查顺序和处理方法

“检查顺序”应按照安全、低风险、易验证和逐步缩小范围的原则组织。例如先核对告警和外部条件，再检查连接与环境，随后进行断电拆检，最后恢复验证。

“处理方法”应明确操作对象、动作、适用条件和完成结果。涉及拆装、更换、接线、送电或参数修改时，必须同时给出安全前提和资料适用范围。

处理方法用于辅助工程师制定检修方案，不代表系统自动执行设备操作。

#### 7.3.5 填写安全要求和恢复标准

“安全要求”至少应覆盖与该知识相关的断电、挂牌、隔离、等待冷却、防静电、人员监护和作业许可要求。涉及不同场站制度时，应说明现场制度优先。

“恢复标准”应包含可观察或可测量的完成条件，例如告警解除、运行参数恢复、业务功能正常和连续观察达到规定时长。不得使用“基本正常”“问题不大”等无法验收的表述。

#### 7.3.6 填写不适用范围

“不适用范围”用于防止知识被错误套用，应明确以下内容：

- 不同型号或硬件版本的限制；
- 现象相似但原因不同的情形；
- 需要厂商或更高权限人员处理的情况；
- 缺少必要测量或证据时不能采用的结论；
- 高风险操作和禁止操作；
- 需要优先排除的传感器、接线或监控系统故障。

适用范围和不适用范围应同时检查。知识越具体，其边界也应越清楚。

### 7.4 知识图谱关系修订

#### 7.4.1 查看关系编辑区

审核第二步下方显示“知识图谱关系”编辑区。每条关系由源节点、关系名称、目标节点和变更类型组成，并在下方生成发布预览。

关系应能够表达清晰、可解释的语义，例如：

- 故障现象“指向”故障领域；
- 判断条件“支持”可能原因；
- 可能原因“关联”故障部件；
- 检查方法“检查”部件或状态；
- 处理方法“解决”故障原因；
- 恢复标准“验证”处理结果；
- 案例“来源于”检修记录；
- 知识条目“依据”手册或案例。

#### 7.4.2 新增图谱关系

选择“新增关系”后，系统增加一行空白关系。依次填写源节点、关系和目标节点，并将变更类型设置为“新增”。

新增前应先检查全局知识图谱中是否存在含义相同的节点和关系。能够复用既有节点时，不应仅因名称不同重复创建。节点名称应采用统一术语，避免同义词导致图谱分裂。

#### 7.4.3 修改或删除图谱关系

既有关系语义不准确、方向错误或适用范围变化时，可将变更类型设为“修改”，并填写修正后的内容。确认关系不再成立时，可设为“删除”或使用删除按钮移出当前变更集。

删除关系前应确认：

1. 关系确实错误或已经失效；
2. 删除不会切断仍然有效的知识路径；
3. 相关知识条目和来源记录已经同步修正；
4. 变更理由能够由手册、案例或专家结论支持。

#### 7.4.4 核对关系方向和来源

关系方向应与语义一致。例如，“现象指向原因”和“原因导致现象”表达方向不同，不能混用。关系名称应简洁稳定，避免使用完整句子或含义模糊的“相关”。

每次关系变更应保留来源案例、关联知识、修改专家和知识版本。无法追溯来源的关系不能直接发布为正式知识。

#### 7.4.5 查看发布预览

关系编辑区下方显示当前保留关系的图形预览。专家应检查节点名称、连接方向、关系语义和变更数量。标记为删除的关系不进入发布预览。

全部知识字段完整，且每条关系的源节点、关系名称和目标节点均有效后，选择“完成知识修正”进入发布确认步骤。

### 7.5 确认和发布知识

#### 7.5.1 查看发布摘要

审核流程第三步集中显示本次发布变化，包括：

- 案例审核结果和专家修订数量；
- 知识版本变化；
- 结构化知识的主要新增或修正内容；
- 图谱关系变更数量及其摘要；
- 来源案例和修改专家；
- 发布后可能影响的检索、诊断和问答范围。

> 【插图位置：图7-4 知识发布确认页面】
> 建议截图展示案例审核结果、知识版本变化、图谱变化、发布影响和确认发布按钮。

发布前只显示重点变化，便于专家集中检查。需要查看完整字段时，可以返回上一步；返回不会丢失已保存草稿。

#### 7.5.2 检查发布影响

专家应检查新知识是否会影响以下功能：

- 异常描述的知识检索结果；
- 智能辅助诊断的原因排序；
- 检修智能体的回答；
- 检修预方案的检查项和安全要求；
- 检修资料推荐；
- 知识图谱中的节点与路径；
- 相似案例的匹配结果。

知识影响范围过大、证据不足或适用边界不清时，应返回修改，不应直接发布。

#### 7.5.3 确认发布

确认内容无误后选择“确认发布”。系统依次完成：

1. 归档案例和专家修订；
2. 生成新的知识版本；
3. 写入知识图谱并绑定来源；
4. 更新发布记录和版本状态。

发布过程中不要重复选择发布按钮或关闭页面。发布完成后，系统进入知识结果页面，并显示发布后的知识版本、内容变化、来源记录和图谱关系。

正式发布属于受控操作。专家应对发布内容的专业正确性、适用范围和安全边界负责。

#### 7.5.4 查看知识发布结果

知识结果页面显示知识条目编号、发布状态、版本变化、发布前后内容差异、来源案例、修改专家、发布时间和已并入图谱的关系。

专家应核对：

- 新版本号符合预期；
- 案例状态已更新；
- 修订内容与发布摘要一致；
- 来源案例和专家信息正确；
- 图谱关系数量及方向正确；
- 知识已进入检修知识库。

发现发布结果与预期不一致时，应停止继续推广该版本，并按照知识版本管理流程处理。

#### 7.5.5 验证知识应用

选择“验证知识应用”，进入知识回流验证页面。输入一段与新知识适用范围相符的异常描述，然后选择“开始验证新知识”。

系统依次解析设备与告警、匹配判断条件、检索知识版本、追溯来源案例并生成推荐动作。验证成功后显示：

- 命中的知识条目和版本；
- 来源案例；
- 命中的异常现象；
- 新增判断；
- 推荐动作；
- 安全要求；
- 恢复标准；
- 不适用范围；
- 本次诊断采用的图谱路径。

### 7.6 全部案例

#### 7.6.1 打开全部案例

在左侧导航选择“全部案例”，进入历史检修案例页面。页面显示案例卡片、搜索框和筛选条件，支持专家查阅不同设备、故障类型、场站和归档状态的案例。

#### 7.6.2 搜索和筛选案例

可以使用以下方式筛选：

- 输入案例编号、设备型号或标题关键词；
- 按故障类型筛选；
- 按场站筛选；
- 按“已归档”或“资料收集中”筛选。

页面显示当前匹配数量。无匹配结果时，应清空部分条件或缩短关键词。多项筛选同时使用时，案例必须同时满足全部条件才会显示。

#### 7.6.3 查看案例详情

选择案例卡片后，详情页显示案例编号、状态、场站、设备、故障现象、最终原因、处理方法、恢复结果、工程师、审核专家和关联知识。

已归档摘要案例以只读方式提供，不支持直接修改或重新审核。需要形成新的修订时，应基于新的检修记录或按知识版本管理流程创建变更，不能覆盖原有历史事实。

#### 7.6.4 使用“资料收集中”案例

“资料收集中”表示案例尚未具备完整证据。专家可以将其用于发现知识缺口，但不得把其中未核实的结论作为正式知识依据。

资料补充完成后，应重新检查设备信息、现场证据、处理过程和恢复验证，再决定归档或进入知识提炼流程。

### 7.7 检修知识库

#### 7.7.1 打开检修知识库

在左侧导航选择“检修知识库”。页面将结构化知识和厂商原始手册分层展示，并显示知识条目数、厂商手册数和已引用资料数。

页面提供两个内容页签：

- **知识条目**：展示案例经验、故障机理、检查方法、处理措施和安全要求；
- **检修手册**：展示设备厂商发布的用户手册、安装手册、维护手册和其他原始资料。

#### 7.7.2 搜索和筛选知识条目

在“知识条目”页签中，可以按知识编号、设备、故障名称或关键词搜索，并按故障类别筛选。知识卡片显示编号、版本、核实状态、标题、摘要、故障类别和来源情况。

核实状态包括官方手册已核实、专家已确认、真实案例已验证或资料收集中。使用知识前应优先核对状态、版本、适用设备和来源。

#### 7.7.3 查看知识条目详情

选择知识卡片后，右侧详情区显示：

- 知识编号和版本；
- 核实状态；
- 适用设备、故障类别和适用范围；
- 当前发布内容；
- 异常现象、可能原因和检查顺序；
- 处理建议和安全要求；
- 恢复标准和适用边界；
- 关联手册、具体页码和来源案例。

专家可以从详情页查看案例版本变化，或选择“在知识图谱中定位”查看该知识的关联节点和关系。

#### 7.7.4 搜索和查看检修手册

切换到“检修手册”页签后，可以按厂商、型号、手册编号或标题搜索，并按厂商筛选。手册卡片显示厂商、出版信息、标题、适用产品、覆盖故障领域、页数和关联知识数量。

选择手册后，详情区显示发布日期、语言、页数、参考等级、覆盖检修领域、已加工知识和使用边界。选择“打开原始 PDF”可以查看完整资料。

#### 7.7.5 识别手册版本和适用边界

手册详情会标明当前版本或历史版本。历史手册仅用于旧设备和版本差异核对，不能直接作为当前设备参数、接口或拆装步骤的依据。

跨型号使用资料时，只能参考已经确认的通用故障机理和检查原则。具体参数、端子定义、接线顺序、拆装步骤和告警阈值必须使用目标设备对应版本的资料。

#### 7.7.6 追溯知识来源

知识条目中的“依据与来源”可以定位到手册名称、厂商和 PDF 页码，也可以关联来源案例。专家应利用来源信息检查结论是否被原始资料或真实案例支持。

形成新知识时，应尽量补充具体资料页码、案例编号和审核记录。只有概括性来源而无具体证据时，应降低知识适用等级或保持“资料收集中”状态。

### 7.8 专家知识图谱

#### 7.8.1 查看全局知识图谱

在左侧导航选择“知识图谱”，进入工控机知识图谱页面。专家端与工程师端使用一致的全局展示方式，支持搜索定位、滚轮缩放、按钮缩放、拖拽平移、节点聚焦和节点详情查看。

“全局知识图谱”用于查看当前已发布的设备、部件、故障、现象、原因、方法、措施、依据、知识和案例关系。选择节点后，页面放大该节点及其一跳关系，并在右侧显示详细信息。

#### 7.8.2 查看本次新增与修改

切换到“本次新增与修改”，页面突出当前案例形成的候选节点和关系，并弱化其他内容。专家可以检查本次变更数量、节点类型、关系方向、来源案例和审核状态。

该视图用于审核变化，不替代第二步中的关系编辑。需要修改关系时，应返回对应案例的专家审核流程；只有完成确认发布后，变更才进入正式图谱。

#### 7.8.3 从图谱进入专家审核

图谱存在待审核候选变更时，页面显示“进入专家审核”。选择该按钮可以返回来源案例的审核流程。

进入审核前，应先选择候选节点查看来源和关联关系，明确需要修订的知识字段及关系，避免在审核页面中失去图谱上下文。

#### 7.8.4 查看发布后的图谱变化

知识发布完成后，“本次新增与修改”显示正式发布状态，候选节点和关系转为已发布内容，并关联知识版本、来源案例和修改专家。

专家应抽查新增路径是否能够从故障现象合理连接到原因、检查方法、处理措施和恢复标准，同时检查是否误连到不适用设备或不相关故障领域。

### 7.9 专家设置

#### 7.9.1 打开专家资料设置

在左侧导航选择“专家设置”。页面包含基本资料、专业能力、账号摘要和保存状态，用于维护专家门户中显示的身份信息和专业范围。

> 【插图位置：图7-8 专家资料设置】
> 建议截图展示基本资料、专业能力、账号摘要、未保存状态和保存资料按钮。

#### 7.9.2 修改基本资料

基本资料包括：

- 显示姓名；
- 专业职称；
- 所属机构或团队。

以上字段为必填项，并会显示在专家侧栏和审核身份区域。填写时应使用真实、规范的工作身份信息，避免使用无法识别责任人的简称。

#### 7.9.3 设置专业能力

专业能力包括擅长领域、审核设备范围和联系方式。擅长领域使用顿号或逗号分隔，最多填写五项；审核设备范围应与专家实际授权和专业能力一致；联系方式为选填项。

专业信息用于说明专家审核边界，不会自动扩大账号权限。超出个人专业范围的案例应转交其他专家或组织联合审核。

#### 7.9.4 查看账号摘要

右侧账号摘要实时显示姓名首字、专业职称、登录账号、所属机构、设备范围、账号状态和专业方向。保存前应通过摘要检查内容是否完整、分隔是否正确和展示长度是否合适。

#### 7.9.5 保存或恢复资料

修改内容后，页面显示“有未保存修改”。选择“保存资料”后，状态变为“资料已保存”。必填字段为空或擅长领域超过五项时，系统提示修改后再保存。

选择“恢复默认”可以将表单恢复为预设资料。执行前应确认是否需要保留当前未保存内容。专家资料设置不改变账号角色、审核权限和知识发布权限，权限调整由用户管理员完成。

## 8. 用户管理后台使用说明

### 8.1 进入用户管理后台

#### 8.1.1 登录管理后台

用户管理员使用管理账号登录系统后，系统进入独立的“用户管理后台”。后台用于维护工程师和专家账号、固定角色、组织归属、账号状态和密码重置，不提供现场检修、专家审核、知识编辑或知识图谱编辑功能。

> 【插图位置：图8-1 用户管理后台首页】
> 建议截图展示“用户与角色管理”标题、管理员账号摘要、用户统计、搜索筛选、用户列表和“新增用户”按钮。

登录后应首先确认：

- 页面标题为“用户与角色管理”；
- 当前账号为用户管理员；
- 页面只显示用户管理相关功能；
- 工程师、专家、正常和停用账号统计能够正常读取；
- 当前操作环境符合单位的账号管理制度。

如果登录后进入工程师端或专家端，说明当前账号角色不是用户管理员，应退出并使用正确账号重新登录。用户管理员不能通过修改页面地址进入其他角色的业务工作区。

#### 8.1.2 查看后台布局

用户管理后台主要由以下区域组成：

1. **后台导航区**：显示用户管理、当前管理员和退出登录；
2. **页面标题区**：显示功能说明和“新增用户”主操作；
3. **统计摘要区**：显示各类用户和账号状态数量；
4. **查询工具栏**：提供关键词搜索、角色筛选和清除条件；
5. **用户列表**：展示用户身份、角色、组织、状态及允许的操作；
6. **用户编辑器**：通过弹窗或抽屉完成新增和编辑；
7. **操作反馈区**：显示保存、启停和密码重置结果。

用户管理员应在同一后台完成账号管理，不需要切换到专家端或工程师端。

#### 8.1.3 退出管理后台

完成管理操作后，选择“退出登录”。系统结束当前管理会话并返回登录页。

在公共计算机或多人共用终端上，不应只关闭浏览器标签页。长时间离开座位前也应主动退出，防止其他人员使用管理员会话修改账号。

### 8.2 用户统计与状态概览

#### 8.2.1 查看用户统计

页面统计卡片显示：

- 工程师数量；
- 专家数量；
- 正常账号数量；
- 停用账号数量。

统计数量与当前用户数据使用同一查询口径。选择统计卡片时，页面可以切换到对应筛选结果，便于快速查看某类用户。

#### 8.2.2 理解账号状态

账号状态分为：

- **正常**：账号可以按照其角色登录对应工作区；
- **停用**：账号不能建立新的登录会话，其历史业务记录仍然保留。

账号停用不是删除用户。检修记录、专家审核、知识发布和操作审计中的人员信息不会因停用而消失。

#### 8.2.3 处理统计加载异常

统计信息无法读取时，页面显示加载失败或不可用状态，而不把未知数量显示为零。用户管理员可以选择重新加载。

统计失败期间，不应根据不完整数字批量执行账号操作。应先恢复数据连接，确认统计与用户列表一致后再继续。

### 8.3 用户列表、搜索与筛选

#### 8.3.1 查看用户列表

用户列表主要显示：

- 姓名和用户编号；
- 登录账号；
- 固定角色；
- 组织归属；
- 账号状态；
- 最近更新时间；
- 编辑、密码重置和启停操作。

工程师的组织归属显示所属场站和班组；专家的组织归属显示所属机构和专业方向。管理员账号不在普通用户列表中作为可编辑对象出现。

> 【插图位置：图8-2 用户列表与搜索筛选】
> 建议截图展示用户编号、姓名、登录账号、角色、组织归属、状态、操作按钮和分页信息。

#### 8.3.2 使用关键词搜索

在搜索框中输入姓名、登录账号、场站、班组、所属机构或专业方向，系统返回匹配用户。搜索时可使用完整信息或有区分度的关键词。

搜索无结果时，应：

1. 检查账号或姓名是否输入错误；
2. 缩短搜索关键词；
3. 清除角色筛选；
4. 检查用户是否已停用；
5. 选择“清除筛选”恢复全部列表。

#### 8.3.3 按角色筛选

角色筛选包括“全部”“工程师”和“专家”。选择角色后，用户列表只显示相应用户，统计和列表总数同步更新。

角色筛选可以与关键词搜索组合使用。例如，先选择“专家”，再输入专业方向，可以定位对应领域的专家账号。

#### 8.3.4 排序和分页

用户列表默认优先显示正常账号，并按最近更新时间排序。用户数量较多时，可以使用分页切换。

切换分页不会清除当前搜索和筛选条件。编辑、启停或重置密码后，系统刷新当前列表；若目标用户因状态变化离开当前筛选范围，可以清除筛选后重新查找。

### 8.4 新增用户

#### 8.4.1 打开新增用户表单

选择页面标题区的“新增用户”，系统打开用户编辑器。新增用户只能选择“工程师”或“专家”角色，不能通过普通表单创建其他用户管理员。

> 【插图位置：图8-3 新增用户表单】
> 建议截图展示姓名、登录账号、角色、组织归属、账号状态、取消和保存按钮。

#### 8.4.2 填写基本信息

新增用户的基本信息包括：

- **姓名**：用户真实姓名或单位规定的显示名称；
- **登录账号**：用户登录时使用的唯一账号；
- **固定角色**：工程师或专家；
- **账号状态**：正常或停用。

姓名和登录账号不能只包含空格。登录账号保存前会进行规范化和唯一性检查，不能与正常或停用账号重复。

#### 8.4.3 填写工程师组织信息

角色选择“工程师”时，需要填写：

- 所属场站；
- 所属班组。

场站和班组用于身份展示、任务分派和数据范围控制。班组应属于所选场站，不能填写相互矛盾的组织组合。

工程师调往其他场站时，应通过编辑用户更新组织归属，不建议重复创建新的登录账号。

#### 8.4.4 填写专家组织和专业信息

角色选择“专家”时，需要填写：

- 所属机构或团队；
- 专业方向。

专业方向用于审核任务筛选和专业范围说明，应使用统一的故障领域或设备领域名称。多个方向之间采用系统规定的分隔方式，避免填写无法检索的长段说明。

#### 8.4.5 保存新增用户

填写完成后选择“保存”。系统依次检查管理员权限、必填字段、登录账号唯一性、角色与组织字段匹配关系，然后创建用户编号并保存账号及组织信息。

保存成功后，页面显示操作结果和审计编号，并刷新用户统计与列表。保存失败时，表单保留已填写内容，并在相应字段显示原因。

#### 8.4.6 处理新增失败

常见失败原因包括：

- 登录账号已经存在；
- 姓名或登录账号格式不符合要求；
- 角色未选择；
- 工程师缺少场站或班组；
- 专家缺少机构或专业方向；
- 组织归属无效；
- 当前管理员会话失效；
- 服务暂时无法保存。

用户记录和组织信息采用同一保存过程。保存失败时不会产生只有账号而没有组织归属的半完成用户。

### 8.5 编辑用户

#### 8.5.1 打开用户编辑器

在目标用户所在行选择“编辑”，系统读取最新用户详情并打开编辑器。编辑前应核对姓名、用户编号、登录账号、当前角色、组织归属和账号状态。

用户编号用于稳定标识人员，编辑后保持不变。修改姓名、角色或组织归属不会覆盖该用户在历史检修记录和审核记录中的人员快照。

#### 8.5.2 修改姓名和登录账号

用户姓名发生规范变更时，可以修改显示姓名。修改登录账号前，应确认新账号符合单位命名规则，并通知用户后续登录方式。

新登录账号仍需通过全系统唯一性检查。不能通过先停用旧账号的方式重复使用同一个登录账号。

#### 8.5.3 修改角色

用户管理员可以在工程师和专家之间调整固定角色。角色改变后，表单自动切换组织字段：

- 工程师转为专家时，需要填写所属机构和专业方向；
- 专家转为工程师时，需要填写所属场站和班组。

角色变更会影响用户下次登录进入的工作区和可使用功能。保存前应确认原有任务已经妥善移交，并按照单位权限审批流程完成授权。

用户管理员不能把普通用户改为管理员，也不能通过用户编辑器修改当前管理员自身角色。

#### 8.5.4 修改组织归属

工程师的场站或班组发生变化、专家的机构或专业方向发生变化时，可以修改组织归属。保存前应检查组织名称、上下级关系和专业范围是否有效。

组织变更用于后续任务分派和数据范围判断，但不会改写历史记录中的原组织信息。

#### 8.5.5 保存用户修改

完成修改后选择“保存”。系统校验数据版本和字段内容，并将用户资料、角色、组织归属和审计记录一并更新。

如果该用户在编辑期间已经被其他管理员修改，系统提示数据版本冲突。此时应关闭编辑器或刷新详情，核对最新内容后重新编辑，不要覆盖他人的有效修改。

### 8.6 启用和停用账号

#### 8.6.1 停用账号

在正常账号所在行选择“停用”。确认窗口显示目标用户、角色、组织归属和停用影响。核对无误后选择确认停用。

> 【插图位置：图8-4 停用账号确认】
> 建议截图展示目标用户、账号、角色、停用影响、取消和确认停用按钮。

停用后：

- 账号不能建立新的登录会话；
- 已有会话在下一次身份校验时失效；
- 用户状态变为“停用”；
- 已分派但未完成的任务应按业务制度重新安排；
- 历史检修、审核、知识和审计记录继续保留。

停用具有明显业务影响，不应把停用作为临时退出或清理列表的手段。

#### 8.6.2 重新启用账号

在停用账号所在行选择“启用”。启用前应检查用户角色、组织归属和专业信息仍然有效，并确认账号恢复符合人员管理要求。

启用后，账号恢复登录资格，但系统不会自动恢复已重新分派的检修任务或审核任务。需要恢复任务时，应由相应业务负责人另行处理。

#### 8.6.3 处理启停异常

账号已处于目标状态时，系统返回当前状态，不重复创建相互矛盾的变更。操作过程中出现数据版本冲突时，应刷新目标用户后重试。

用户管理员不能停用当前自身账号或其他管理员。没有权限的启停请求会被拒绝，并形成安全审计记录。

### 8.7 密码重置

#### 8.7.1 发起密码重置

当工程师或专家无法使用原密码登录时，用户管理员可以在目标用户所在行选择“重置密码”。确认窗口显示目标用户、登录账号、角色和操作影响。

> 【插图位置：图8-5 密码重置确认与结果】
> 建议截图展示目标账号、重置影响、确认按钮，以及成功后的有效方式和审计编号；不要展示真实密码。

执行前应通过单位规定的方式确认申请人身份，避免为错误账号或未经授权的人员重置密码。

#### 8.7.2 确认密码重置

确认后，系统创建一次性重置凭据或将账号设置为需要重新设定密码的状态，并根据安全策略使受影响的旧凭据失效。

操作成功后，页面只显示处理成功、有效范围、取得新凭据的方式和审计编号。用户管理员不能读取用户原密码。

#### 8.7.3 传递重置凭据

一次性凭据应通过单位认可的安全方式交付给目标用户，并提醒用户在首次登录后立即设置新密码。不得通过公开群聊、长期邮件正文或普通业务记录传递长期有效密码。

页面、普通日志和检修文档不得长期保存明文密码或一次性凭据。凭据超过有效期后，应重新发起重置。

#### 8.7.4 处理密码重置失败

密码重置可能因管理员会话失效、目标账号状态异常、数据版本变化或服务不可用而失败。失败时，系统不会显示原密码，也不会生成无法追溯的临时口令。

用户管理员应刷新用户状态，确认目标账号后重新操作。连续失败时，应记录审计编号或错误提示并联系系统运维人员。

### 8.8 操作结果与安全边界

#### 8.8.1 查看操作反馈

新增、编辑、启停和密码重置完成后，页面显示成功或失败反馈。成功反馈包括操作对象、结果状态和审计编号；失败反馈说明未完成原因，并保留可继续处理的信息。

页面提示成功后，用户管理员应在列表中再次核对目标用户和状态。统计数字、列表状态和用户详情应保持一致。

#### 8.8.2 理解审计记录

以下操作均形成审计记录：

- 新增用户；
- 修改姓名或登录账号；
- 调整角色；
- 修改组织归属；
- 启用或停用账号；
- 发起密码重置；
- 被拒绝的无权限操作。

审计信息记录操作人员、目标用户、操作时间、关键字段变化和处理结果，不记录原密码、密码摘要或长期明文凭据。

#### 8.8.3 管理员权限边界

用户管理员只能维护工程师和专家账号及其组织信息。用户管理员不能：

- 执行或修改现场检修任务；
- 修改工程师已经确认的检修事实；
- 审核专家案例；
- 编辑或发布检修知识；
- 编辑知识图谱节点和关系；
- 创建其他管理员；
- 通过普通用户列表修改自身角色或状态；
- 查看用户原密码；
- 读取数据库密码、模型密钥或其他部署凭据。

系统部署、服务启停、数据库备份和密钥配置属于部署运维职责，不因拥有用户管理员角色而自动获得权限。

#### 8.8.4 处理后台连接异常

后台服务无法连接时，页面显示失败状态和重新加载入口，不使用浏览器中的旧数据接受正式修改。用户管理员应停止新增、编辑和安全操作，避免重复提交。

连接恢复后，应重新加载统计和列表，核对目标用户的最新状态，再决定是否重新执行操作。

## 9. 通用操作与异常处理

### 9.1 页面导航与内容刷新

#### 9.1.1 使用一级导航

工程师端、专家端和用户管理后台均通过左侧导航进入当前角色的主要功能。当前页面对应的导航项使用选中状态显示。

切换一级导航时，系统保留已经正式保存的业务内容。正在填写但尚未保存的表单可能丢失，因此离开长表单或审核流程前，应先选择“保存草稿”或完成当前保存操作。

#### 9.1.2 返回上一业务页面

详情页和流程页提供“返回工作台”“返回列表”或“上一步”等按钮。应优先使用页面提供的返回按钮，以保持当前任务、筛选条件和业务状态。

浏览器后退按钮只能作为辅助方式。涉及提交、发布、启停或密码重置后，不应依赖浏览器后退恢复操作前状态，应重新读取当前业务结果。

#### 9.1.3 刷新页面

页面显示数据未更新、网络短时中断或操作状态不确定时，可以刷新页面。刷新前应确认当前输入是否已经保存。

刷新后，系统从服务端读取已保存的任务、记录、审核、知识版本或用户状态。未提交的临时输入不作为正式结果，不能仅凭按钮曾被选择就认定操作已经完成。

### 9.2 搜索、筛选和详情查看

#### 9.2.1 使用关键词搜索

知识库、案例、检修记录、知识图谱和用户列表均提供关键词搜索。建议优先使用具有区分度的业务信息，例如：

- 设备型号或设备类别；
- 故障名称、告警名称或部件名称；
- 案例编号、记录编号或知识编号；
- 手册厂商和出版信息；
- 用户姓名、登录账号或组织名称。

搜索词过长时，可先输入核心名词，再使用筛选条件缩小范围。

#### 9.2.2 组合筛选条件

多个筛选条件同时生效时，结果通常需要满足全部条件。未找到目标内容时，应逐项清除筛选条件，确认是搜索词不匹配还是内容确实不存在。

筛选结果为零表示当前条件没有匹配内容；页面显示“加载失败”或“不可用”则表示数据未能读取，两者含义不同。

#### 9.2.3 打开和关闭详情

选择列表行、卡片或图谱节点后，系统打开详情页、抽屉或右侧详情面板。阅读完成后，使用关闭按钮、返回按钮或选择空白区域退出详情。

详情内容包含来源、版本和适用范围时，应先核对这些信息，再采用其中的结论或操作方法。

### 9.3 表单填写、保存和确认

#### 9.3.1 识别必填字段

带“必填”标识的字段必须填写。按钮不可使用时，应检查：

- 必填字段是否为空；
- 数字字段是否输入了有效数值；
- 单位、日期或账号格式是否正确；
- 当前步骤的检查项是否全部确认；
- 是否存在未处理的安全确认；
- 当前账号是否具有对应权限。

#### 9.3.2 保存草稿

“保存草稿”用于保留尚未提交的阶段性内容。保存草稿后，内容仍可以继续修改，但不会产生以下结果：

- 不会完成检修步骤；
- 不会提交专家审核；
- 不会发布知识或图谱；
- 不会启停用户；
- 不会完成密码重置。

页面显示保存成功后，再离开当前编辑区域。保存失败时，保留页面输入并按提示重试。

#### 9.3.3 执行提交或确认

“提交”“确认”“完成并继续”等操作会推动业务状态变化。执行前应检查页面摘要、关键字段和影响说明。

提交后等待页面显示明确成功状态。网络较慢时不要连续选择按钮，避免重复请求。页面结果不确定时，应重新加载目标任务或记录确认当前状态。

#### 9.3.4 执行高影响操作

知识发布、图谱发布、账号停用、密码重置和恢复供电属于高影响操作。系统会显示确认信息或安全提示。

执行者应核对操作对象、当前状态、影响范围和后续措施。确认窗口中的对象信息不正确时，应选择取消，不要继续操作。

### 9.4 文件上传、预览和材料处理

#### 9.4.1 选择文件

上传现场材料或检修资料时，应选择与当前任务直接相关的图片、视频、音频或文档。上传前检查文件名称、格式、大小、内容和敏感信息。

同一故障可以上传多项材料。建议使用能够说明内容的文件名，例如包含检查位置、时间或处理阶段，避免使用大量无法区分的默认文件名。

#### 9.4.2 查看上传状态

文件处理可能显示等待、上传中、处理中、待复核、已完成、部分完成、失败或已取消。单个文件失败不影响其他已成功材料。

上传期间不要关闭页面或重复选择同一文件。处理完成后，应查看材料数量和缩略图，确认文件已经关联到当前任务。

#### 9.4.3 预览材料

选择材料缩略图或名称可以打开预览。图片应检查关键部位是否清晰；视频和音频应检查内容是否完整；文档应核对标题、版本和适用设备。

预览失败不一定表示原文件损坏。可以尝试重新打开或下载后使用本地程序查看。仍无法读取时，应重新上传有效文件。

#### 9.4.4 删除或替换材料

材料尚未提交为正式记录时，可以删除错误文件并重新上传。删除前应确认选择的是当前材料，而不是同名的其他文件。

已经被检修记录、案例、知识或作业卡引用的材料，应按照归档和版本规则处理，不直接删除来源证据。

### 9.5 语音输入与语音播报

#### 9.5.1 使用语音输入

异常描述和智能问答输入区提供麦克风入口时，可以使用语音输入。首次使用需要允许浏览器访问麦克风。

语音输入的一般步骤为：

1. 选择麦克风按钮；
2. 允许麦克风权限；
3. 清楚说出需要输入的内容；
4. 选择停止或等待录音结束；
5. 等待识别文字回填；
6. 检查并修正识别结果；
7. 由用户主动提交文字。

语音识别完成后不会自动提交异常或发送问题。关键设备名称、接口名称、数值和单位必须人工核对。

#### 9.5.2 处理麦克风权限问题

浏览器拒绝麦克风权限时，可以继续使用键盘输入。需要恢复语音功能时，在浏览器地址栏的网站权限中允许麦克风，然后重新进入页面或刷新。

公共终端使用完毕后，可以按管理要求关闭麦克风权限。语音输入的临时音频不作为现场附件长期保存；需要保留的声音证据应通过现场材料功能单独上传。

#### 9.5.3 使用语音播报

检修向导中的语音播报只播报当前步骤和相关安全提示。切换步骤后再次选择语音播报，系统会使用新的步骤内容。

播报内容听辨不清、现场噪声过大或涉及危险操作时，应停止播报并阅读页面原文。语音播报不能替代作业票、安全交底和现场口头确认。

### 9.6 处理进度和系统状态

#### 9.6.1 识别常见状态

系统常见状态及处理方式如下：

| 状态 | 含义 | 用户操作 |
| --- | --- | --- |
| 等待处理 | 请求已经接收，尚未开始 | 保持页面或稍后查看 |
| 处理中 | 系统正在执行识别、生成或发布 | 等待完成，不重复提交 |
| 待复核 | 自动结果已经生成，需要人工确认 | 核对内容并确认或修改 |
| 已完成 | 当前操作成功完成 | 进入下一业务步骤 |
| 部分完成 | 部分材料或处理通道成功 | 查看失败项并决定是否重试 |
| 失败 | 当前操作没有形成有效结果 | 按提示修正或重试 |
| 已取消 | 用户或系统终止处理 | 确认是否需要重新发起 |

#### 9.6.2 等待智能处理

诊断、问答、资料解析、语音识别和知识验证可能需要一定时间。页面会显示当前处理阶段或进度。

处理期间不要连续重复提交相同内容。达到等待上限后，页面会给出重试、查看已有资料或改用人工处理的入口。

#### 9.6.3 处理中断后继续

浏览器刷新、网络中断或设备重启后，重新登录并进入原任务。系统从最后一个已确认且保存成功的步骤继续。

页面上曾经勾选但未保存成功的检查项不视为完成。恢复任务后，应重新核对现场设备状态，特别是供电、拆装、隔离和安全条件。

### 9.7 打印、下载和文件保存

#### 9.7.1 选择保存位置

导出 PDF、下载手册或保存其他文件时，应选择符合单位资料管理要求的目录。文件名应保留记录编号、案例编号、知识编号、版本或日期等识别信息。

不要将含有现场信息、人员信息或设备信息的文件长期保存在公共下载目录。

#### 9.7.2 检查下载文件

下载完成后，应检查文件名称、大小、格式和内容。PDF 文件需要打开确认页数、中文显示、表格、图片和页脚完整。

同名文件已存在时，不应无提示覆盖旧版本。可以在文件名中增加版本或时间，保留必要的历史文件。

#### 9.7.3 处理浏览器下载拦截

浏览器阻止下载或弹出窗口时，应检查地址栏提示，允许当前可信系统执行本次下载。不要为无关网站长期开放不受限制的下载权限。

### 9.8 常见异常处理

#### 9.8.1 登录失败

账号或密码错误时，系统显示统一登录失败提示。用户应检查输入法、大小写和账号信息后重试。

账号已停用、密码重置后无法登录或多次失败时，应联系用户管理员。系统不会在登录页区分账号不存在和密码错误的具体原因。

#### 9.8.2 会话失效

长时间未操作、账号状态变化或认证信息过期时，系统返回登录页。重新登录后，从工作台进入原任务并检查已保存状态。

会话失效期间未保存的输入可能需要重新填写。高影响操作应以重新加载后的正式状态为准。

#### 9.8.3 权限不足

直接访问其他角色页面或执行无权限操作时，系统显示无权访问。用户应返回当前角色工作区，不要反复修改页面地址尝试进入。

确需调整角色或组织范围时，由用户管理员按授权流程处理。用户不能通过个人设置提升自身权限。

#### 9.8.4 网络连接异常

网络中断时，应先保留现场安全状态和必要的人工记录。页面恢复连接后，重新加载任务确认最后保存位置。

不要在连接不稳定时反复提交同一表单。涉及知识发布、账号停用和密码重置时，必须读取最新结果后再决定是否重试。

#### 9.8.5 保存失败或数据冲突

保存失败时，页面保留当前输入并提示重试。数据已被其他用户修改时，系统提示版本冲突。

发生冲突后，应读取最新数据，对比他人修改，再重新填写需要保留的内容。不要直接覆盖新的审核结论、知识版本或用户资料。

#### 9.8.6 文件处理失败

文件上传、OCR、转写、解析或预览失败时，原文件和其他成功材料保持不变。用户可以重新处理、重新上传或改为人工录入。

文件格式、扩展名和实际内容不一致时，应使用正确程序重新导出文件，不要只修改扩展名。

#### 9.8.7 智能诊断或问答不可用

智能服务超时或暂时不可用时，系统保留已输入事实和已选资料。工程师可以继续查看原始手册、历史案例、知识条目和知识图谱，并按现场制度进行人工判断或请求专家支持。

智能服务不可用不应阻断断电、隔离、告警上报等必要安全处置。恢复后可以基于已保存事实重新发起诊断或问答。

#### 9.8.8 知识图谱加载失败

图谱服务不可用时，页面显示重新加载入口。用户可以改从检修知识库查看知识条目和来源资料。

图谱加载失败不表示知识条目不存在。恢复后重新打开图谱，并使用知识编号或节点名称定位。

#### 9.8.9 作业卡生成或打印失败

作业卡生成失败不会删除检修记录。用户可以检查必填字段、浏览器打印设置、字体和文件保存权限后重试。

生成的 PDF 无法打开、页数异常或内容截断时，不应归档该文件。应重新生成并检查，原有效版本不因失败操作被覆盖。

#### 9.8.10 区分空数据与服务不可用

“没有匹配内容”“尚无记录”表示系统已经正常查询，但当前没有数据；“加载失败”“服务不可用”表示无法确认数据情况。

服务不可用时，不应将未知状态记录为零条案例、零条知识或无故障。应恢复服务并重新查询。

## 10. 典型业务操作流程

### 10.1 工程师完成一次检修闭环

#### 10.1.1 适用场景和准备条件

本流程适用于工程师从现场发现工控机异常开始，完成辅助诊断、检修执行、恢复验证和记录提交。开始前应具备：

- 有效工程师账号；
- 明确的场站、设备和异常信息；
- 必要的现场作业许可和安全条件；
- 可以使用的设备手册或检修知识；
- 现场检查、测量和材料采集条件。

#### 10.1.2 操作步骤

1. 登录工程师端并进入“工作台”；
2. 选择“开始现场接诊”；
3. 输入或语音录入异常描述；
4. 上传现场图片、视频或音频；
5. 从“检修资料”选择相关手册、案例和知识；
6. 确认发生时间、地点、设备、角色、告警和运行参数；
7. 启动智能辅助诊断，查看故障方向、依据和安全提示；
8. 对诊断结论或当前资料进行追问；
9. 确认诊断结论并生成检修预方案；
10. 修改步骤顺序或内容，保留强制安全项；
11. 确认方案并进入检修向导；
12. 按顺序完成每一步检查项并记录实际结果；
13. 需要时使用当前步骤追问、语音播报或专家视频会诊；
14. 完成恢复前检查，由授权人员恢复运行；
15. 记录告警状态、运行参数、观察时间和遗留风险；
16. 生成检修记录并完善最终原因、实际处理和恢复结果；
17. 打印或导出两页检修作业卡；
18. 提交专家审核。

#### 10.1.3 完成标志

工程师侧流程完成后，应同时满足：

- 检修步骤全部确认；
- 恢复结论明确；

- 检修记录已生成；
- 作业卡可以正常查看或导出；
- 案例状态为“待专家审核”。

### 10.2 专家审核并发布知识

#### 10.2.1 适用场景和准备条件

本流程适用于工程师已经提交完整检修记录，需要专家核对事实、修正结论并决定是否沉淀知识。专家应使用具有相应专业范围的账号。

#### 10.2.2 操作步骤

1. 登录专家端并进入“专家工作台”；
2. 找到状态为“待专家审核”的案例；
3. 进入“审核并修正案例”；
4. 核对只读的工程师现场事实、步骤、材料和恢复参数；
5. 选择“修正后通过”“退回补充”或“仅归档案例”；
6. 修正最终原因、实际处理、恢复结果和知识沉淀价值；
7. 保存审核草稿；
8. 进入“修正知识与知识图谱”；
9. 完善适用设备、现象、条件、原因、检查、措施、安全、恢复和排除范围；
10. 新增、修改或删除图谱关系；
11. 查看关系预览并完成知识修正；
12. 在发布摘要中检查案例、知识版本和图谱变化；
13. 确认发布正式知识；
14. 查看知识版本、来源案例和图谱发布结果；
15. 使用相似异常验证新知识是否能够被检索。

#### 10.2.3 退回补充分支

证据缺失或恢复验证不足时，专家选择“退回补充”，明确需要补充的字段和判断标准。工程师补充后重新提交，专家继续审核。

退回补充不会删除原始记录，也不会把未确认内容发布到知识库或知识图谱。

#### 10.2.4 完成标志

发布流程完成后，应同时满足：

- 案例具有明确审核决定；
- 专家修订内容已保存；
- 新知识具有版本号和适用边界；
- 图谱关系可追溯到来源案例；
- 发布结果显示成功；
- 知识验证能够显示命中版本或明确的不匹配原因。

### 10.3 查看知识图谱和同步新知识

#### 10.3.1 专家查看变更

专家进入“知识图谱”，切换“本次新增与修改”，选择候选节点检查来源、关系方向和审核状态。需要调整时，从图谱进入来源案例审核流程。

发布完成后，再次查看本次变化，确认候选内容已经转为正式发布状态。

#### 10.3.2 工程师查看和同步版本

工程师进入“知识图谱”，查看顶部知识版本状态。发现服务器存在新发布版本时：

1. 查看“本次新增与修改”；
2. 核对新增知识和关系来源；
3. 选择同步到最新版本；
4. 等待同步完成；
5. 检查本地版本状态；
6. 使用节点定位或现场知识验证确认新版本已经生效。

同步失败时，工程师端继续使用原正式版本，不会使用未完整同步的知识。

#### 10.3.3 完成标志

知识版本号、本次新增关系和节点详情保持一致；工程师端显示本地知识已经是最新版本；检索或问答结果能够追溯到新知识及其来源案例。

### 10.4 生成并归档检修作业卡

#### 10.4.1 操作步骤

1. 打开已生成的检修记录；
2. 核对最终原因、实际处理、恢复结果和遗留风险；
3. 核对处理前后参数、已完成步骤和现场材料；
4. 选择“打印作业卡”；
5. 在打印预览中选择 A4、纵向和正确页数；
6. 选择打印机完成纸质输出，或选择“另存为 PDF”；
7. 使用包含记录编号和日期的文件名保存；
8. 打开 PDF 检查两页内容；
9. 按单位要求归档或提交复核。

#### 10.4.2 完成标志

作业卡共两页，记录编号一致，内容无截断，参数和结论与检修记录一致，签字区和页码完整，PDF 可以正常打开。

### 10.5 用户管理员维护账号

#### 10.5.1 新增账号流程

1. 使用用户管理员账号登录后台；
2. 选择“新增用户”；
3. 填写姓名和唯一登录账号；
4. 选择工程师或专家角色；
5. 按角色填写场站班组或机构专业方向；
6. 核对账号状态；
7. 保存用户；
8. 查看成功反馈和审计编号；
9. 在列表中确认用户和统计数量。

#### 10.5.2 人员岗位变化流程

1. 搜索并打开目标用户；
2. 核对用户编号，避免选择同名人员；
3. 修改角色或组织归属；
4. 补齐目标角色对应的组织字段；
5. 确认原有任务已经妥善移交；
6. 保存并查看操作结果；
7. 通知用户重新登录核对工作区。

#### 10.5.3 离岗停用流程

1. 搜索目标用户并核对身份；
2. 确认未完成任务和责任交接情况；
3. 选择“停用”；
4. 阅读影响说明并确认；
5. 检查账号状态变为“停用”；
6. 保留历史检修、审核和知识记录；
7. 按需要重新分派未完成任务。

#### 10.5.4 密码重置流程

1. 按单位制度确认用户身份；
2. 在用户列表中选择“重置密码”；
3. 核对目标账号和角色；
4. 确认重置；
5. 记录操作结果和审计编号；
6. 通过安全方式交付一次性凭据；
7. 提醒用户登录后设置新密码。

### 10.6 跨角色知识闭环

#### 10.6.1 闭环关系

一次完整的知识闭环由三个角色依次参与：

1. 工程师记录真实现场事实并完成检修；
2. 专家复核案例，提炼并发布知识；
3. 工程师同步新知识并在后续任务中使用。

用户管理员只保障账号、角色和组织信息正确，不参与专业结论和知识发布。

#### 10.6.2 责任边界

- 工程师对现场事实、实际操作和恢复结果负责；
- 专家对审核结论、知识内容、适用边界和图谱关系负责；
- 用户管理员对账号、角色、组织和安全状态维护负责；
- 系统提供记录、检索、提示、生成和追溯能力，不替代责任人员确认。

#### 10.6.3 闭环完成标志

检修记录能够追溯到工程师，知识版本能够追溯到专家和来源案例，图谱关系能够追溯到知识版本，工程师端能够确认当前使用的正式知识版本。各角色操作均保留状态和责任信息。

| 状态类别 | 典型状态 | 说明 |

### 11.4 知识和图谱版本

知识条目、知识图谱和工程师端本地知识均具有版本信息：

- **知识条目版本**记录专家对结构化知识的正式修订；
- **知识图谱版本**记录节点和关系的发布批次；
- **本地知识版本**表示当前参与工程师端检索、诊断和问答的知识范围；
- **检修记录引用版本**表示任务当时实际使用的知识版本。

新版本发布不会改写历史检修记录引用的旧版本。工程师同步后，新版本用于后续任务；已经归档的任务仍保留当时的知识依据。

知识版本变化至少能够追溯到来源案例、修改专家、发布时间和图谱变更。未发布草稿和候选关系不作为正式知识参与现场诊断。

### 11.5 数据来源和人工确认

页面内容可能来自以下来源：

- 工程师文字或语音识别后的人工确认；
- 现场图片、视频和音频；
- 设备台账和运行监控参数；
- 厂商手册、安装手册和维护资料；
- 已发布知识条目和知识图谱；
- 历史检修案例；
- 智能识别、检索和生成结果；
- 专家审核结论；
- 用户管理员维护的账号和组织资料。

系统生成内容与人工确认内容在页面中使用不同状态或字段展示。用户应检查来源、适用范围和当前确认人，不能把自动生成内容直接视为已经核实的现场事实。

### 11.6 现场材料和文件数据

现场材料分为图片、视频、故障录音和文档。材料进入正式检修记录后，与任务、记录和案例建立关联。

短时语音输入仅用于识别文字，识别完成、取消或失败后按临时数据规则处理，不等同于作为证据保存的故障录音。需要长期保留的声音证据必须通过现场材料入口接入。

资料文件的原文件、解析文字、页码引用和知识条目分别管理。解析失败不会改变原文件；历史手册与当前版本手册通过版本和适用范围区分。

### 11.7 时间、数值和单位

用户填写和核对数据时应注意：

- 发生时间、处理时间、观察时间和发布时间使用一致时区；
- 温度明确使用摄氏度；
- 风扇转速明确使用 rpm；
- 电压、电流、湿度、存储容量和通信参数使用对应标准单位；
- 处理前后数值来自相同或可比较的采集位置和方法；
- 人工录入值与设备自动采集值应能够区分；
- 未测量的字段填写“未记录”，不得填入推测数值。

阈值只在适用设备、环境和资料版本范围内使用。页面建议值不能替代目标设备手册和现场标准。

### 11.8 来源追溯关系

系统通过以下关系保持检修知识可追溯：

```text
现场异常 → 检修任务 → 检修记录 → 审核案例 → 知识版本 → 图谱关系
     └──────── 手册、材料、运行参数和人员确认 ────────┘
```

查阅知识时，可以从知识条目查看来源手册页码和案例；查阅案例时，可以查看来源记录和工程师；查阅记录时，可以查看任务、步骤、材料和当时使用的知识依据。

## 12. 使用注意事项

### 12.1 现场安全注意事项

1. 软件提供检修辅助信息，不替代现场安全制度、作业许可和人员资质要求；
2. 涉及开盖、拆装、接线或部件更换前，应正常关机、切断所有电源并确认隔离；
3. 设备断电后应等待储能释放和部件冷却；
4. 接触主板、扩展卡、内存、存储和接口部件时，应落实防静电措施；
5. 送电和恢复运行必须由有权限的现场人员确认执行；
6. 存在高温、凝露、粉尘、振动、腐蚀、带电或其他危险环境时，应先执行现场风险控制；
7. 页面步骤与现场条件冲突时，应暂停操作并请求负责人或专家确认；
8. 不得为了推进页面进度而虚假确认未执行的检查项。

### 12.2 智能辅助能力使用边界

系统中的设备识别、OCR、语音识别、知识检索、诊断分析、问答和方案生成均属于辅助能力。使用时应遵守以下原则：

- 自动识别结果必须由用户核对；
- 诊断结论必须结合现场事实和资料依据确认；
- 问答内容不能代替对应设备手册；
- 生成的检修方案必须由工程师修改确认；
- 数值、接口、接线和拆装信息必须核对原始资料；
- 来源不足或相互冲突时，不形成确定结论；
- 智能服务不可用时，保留人工录入、资料浏览和专家支持路径；
- 系统不自动控制设备启停、送电或硬件操作。

### 12.3 手册和知识适用性

使用手册、案例和知识条目前，应核对：

- 设备类别、品牌、系列和具体型号；
- 硬件版本、结构和接口标识；
- 手册版本、发布日期和语言；
- 安装环境和现场角色；
- 知识的指定型号、同系列或通用适用等级；
- 不适用范围和排除条件；
- 手册与现场设备是否存在版本差异。

历史手册只能用于旧设备或版本差异对照。跨型号资料只能参考已确认的通用机理，不直接套用端子定义、线序、阈值和拆装步骤。

### 12.4 运行参数注意事项

运行参数用于支持判断和恢复验证。用户应记录采集位置、时间、单位和方法，并检查仪表或监控数据是否可信。

单次正常读数不代表故障已经消除，应结合告警变化、参数趋势、设备负载和连续观察结果。传感器、采集接口或监控模块本身异常时，应先确认数据有效性。

### 12.5 角色与责任注意事项

- 工程师不能把未执行步骤标记为完成，也不能用智能建议替代现场确认；
- 专家不能修改工程师原始现场证据，只能修正专业结论和知识表达；
- 专家发布知识前必须检查证据、适用范围、安全要求和图谱关系；
- 用户管理员不能参与专业审核或知识发布；
- 普通用户不能通过个人设置提升角色和权限；
- 任何角色都不能使用他人账号执行操作；
- 人员岗位变化时应先完成任务和责任交接，再修改账号角色或状态。

### 12.6 文件与信息安全

上传材料、导出作业卡和反馈问题时，应避免泄露：

- 登录密码和一次性重置凭据；
- 访问令牌、模型密钥和数据库凭据；
- 与检修无关的个人隐私；
- 未经授权公开的场站、网络和设备信息；
- 其他单位规定的敏感信息。

包含业务信息的文件应保存在受控目录，不长期存放于公共下载目录。公共终端使用完毕后，应退出账号并清理符合规定的临时下载文件。

### 12.7 知识发布注意事项

知识发布前应完成案例审核、结构化字段检查、关系预览、来源追溯和适用范围确认。发布过程中不要重复操作。

发布失败时保留上一正式版本和当前草稿，不把部分成功内容作为完整版本使用。发现已发布知识存在问题时，应通过版本修订或回退流程处理，不直接覆盖历史来源和审核记录。

### 12.8 浏览器和终端使用注意事项

- 推荐使用受支持的现代桌面浏览器；
- 浏览器缩放建议保持在适合当前分辨率的范围；
- 使用语音功能前检查麦克风权限；
- 打印作业卡前检查 A4、方向、缩放和页数；
- 不在多个标签页同时编辑同一任务、审核草稿或用户资料；
- 页面长时间打开后，提交前先确认会话仍然有效；
- 浏览器提示下载或弹出窗口时，只对可信系统地址授予必要权限。

### 12.9 记录和归档注意事项

检修记录、案例、知识版本和作业卡应保留业务编号、人员、时间和版本。纸质作业卡签字后，应按单位制度归档；电子 PDF 应检查可打开性和内容完整性。

用户姓名、组织或角色变化不改写历史责任信息。账号停用不删除历史检修和审核记录。需要更正已归档内容时，应形成修订或补充记录，不无提示覆盖原版本。

## 13. 常见问题

### 13.1 登录与账号问题

#### 13.1.1 登录后为什么进入了错误的工作区？

系统根据账号角色自动进入工作区。请先核对页面显示的姓名和角色；不正确时退出登录并联系用户管理员检查账号角色。用户不能在登录页自行切换角色。

#### 13.1.2 为什么账号和密码正确仍然无法登录？

账号可能已停用、凭据已重置或会话服务暂时不可用。检查统一提示后联系用户管理员核对账号状态。不要连续高频尝试密码。

#### 13.1.3 忘记密码怎么办？

联系用户管理员发起密码重置。管理员不能查看原密码，只能按照安全流程创建一次性凭据或要求用户重新设置密码。

#### 13.1.4 为什么看不到某个功能入口？

导航按角色和权限显示。工程师、专家和用户管理员的入口不同。确认当前角色和组织范围；确需调整时联系用户管理员。

### 13.2 异常接入与诊断问题

#### 13.2.1 语音识别不准确怎么办？

在输入框中直接修改识别文字。重点检查设备型号、告警名称、接口名称、数字和单位。环境噪声较大时改用键盘输入。

#### 13.2.2 图片或视频上传失败怎么办？

检查文件格式、大小、网络和浏览器权限后重试。单项失败不会清除文字描述和其他成功材料。文件损坏时应重新导出或重新采集。

#### 13.2.3 没有找到匹配的检修资料怎么办？

缩短关键词，按设备类别或故障领域查看通用知识，再核对厂商手册。仍无适用资料时，可以继续人工填写现场事实并请求专家支持，不能使用明显不适用的型号资料。

#### 13.2.4 系统识别的设备型号不正确怎么办？

在设备与故障信息确认页面修改型号，并重新核对角色、告警和资料。人工确认值作为当前任务依据，不应保留错误型号继续诊断。

#### 13.2.5 智能诊断长时间没有结果怎么办？

查看处理状态和网络连接，避免重复提交。达到等待上限后使用重试入口；也可以先查看已选手册、历史案例和知识条目，或请求专家支持。

### 13.3 检修向导与恢复问题

#### 13.3.1 为什么“完成并继续”按钮不能使用？

当前步骤可能仍有未确认检查项，或系统正在保存和生成下一步。核对检查项数量、安全要求和页面状态。只有实际完成检查后才能确认。

#### 13.3.2 当前步骤提示与现场设备不一致怎么办？

立即暂停操作，核对设备型号、硬件版本和资料来源。返回修改任务信息或请求专家会诊，不要强行套用当前步骤。

#### 13.3.3 如何询问 FAN 接线顺序或风扇低速原因？

进入“检查滤网、风扇和接线”步骤，在右侧检修智能体输入问题。回答后仍需核对目标设备手册、接口标识和现场测量结果。

#### 13.3.4 恢复供电后告警又出现怎么办？

不要判定恢复成功。记录复发时间和参数，保持或恢复安全状态，返回相关步骤重新检查，必要时请求专家支持。

#### 13.3.5 参数恢复正常后可以立即结束吗？

不可以只依据单次读数结束。应完成规定的连续观察，检查告警、参数趋势、业务功能和遗留风险，再确认恢复结论。

### 13.4 检修记录和作业卡问题

#### 13.4.1 为什么不能提交专家审核？

检查最终原因、实际处理、恢复结果、关键参数和观察时间是否完整，并确认检修步骤已经完成。必填结果缺失时不能提交。

#### 13.4.2 检修记录中的内容可以修改吗？

提交专家审核前，工程师可以完善可编辑结果。提交后，现场事实进入受控状态；需要更正时应按退回补充或修订流程处理。

#### 13.4.3 PDF 作业卡内容被截断怎么办？

在打印预览中选择 A4、纵向和合适的缩放，确认页数为两页。仍有问题时检查浏览器打印边距、字体和页面缩放后重新生成。

#### 13.4.4 作业卡生成失败会丢失检修记录吗？

不会。作业卡是根据检修记录生成的输出文件，生成失败不删除检修记录。修正问题后可以重新生成。

### 13.5 专家审核和知识问题

#### 13.5.1 专家可以修改工程师上传的现场证据吗？

不能。现场证据和工程师确认结果保持来源责任。专家发现问题时应退回补充；专家可以修正专业结论、知识字段和图谱关系。

#### 13.5.2 “修正后通过”“退回补充”和“仅归档案例”如何选择？

证据完整且可以形成可靠知识时选择“修正后通过”；证据不足或矛盾时选择“退回补充”；案例有记录价值但不适合形成可复用知识时选择“仅归档案例”。

#### 13.5.3 保存草稿后知识会立即生效吗？

不会。草稿仅保存专家当前修改。完成审核、发布和版本更新后，知识才成为正式内容；工程师端还需使用已同步的正式版本。

#### 13.5.4 发布后为什么验证没有命中新知识？

检查验证输入是否符合适用范围、知识版本是否发布成功、工程师端是否已同步，以及输入是否触发了排除条件。验证不匹配时不应修改真实事实来强制命中。

#### 13.5.5 知识图谱节点很多，如何快速查看局部关系？

使用搜索框定位节点，选择节点后页面会聚焦其一跳关系。可以使用滚轮或按钮缩放、拖拽平移，并用“返回全局”恢复整体视图。

### 13.6 用户管理问题

#### 13.6.1 新增用户时提示登录账号重复怎么办？

登录账号在正常和停用用户中均要求唯一。先搜索该账号，确认是否已有用户；不要通过重复创建解决人员调动问题。

#### 13.6.2 修改角色后为什么不能保存？

角色变化后必须填写目标角色对应的组织字段。工程师需要场站和班组，专家需要所属机构和专业方向。

#### 13.6.3 停用账号会删除历史记录吗？

不会。停用只阻止新的登录会话，历史检修、审核、知识和审计记录继续保留原人员信息。

#### 13.6.4 重新启用账号会恢复原任务吗？

不会自动恢复已经重新分派的任务。启用只恢复登录资格，任务安排由相应业务负责人处理。

### 13.7 系统使用问题

#### 13.7.1 页面显示“没有数据”和“加载失败”有什么区别？

“没有数据”表示查询正常但当前无匹配内容；“加载失败”表示无法确认是否存在数据。后者应重新加载，不能按零数据处理。

#### 13.7.2 网络中断后从哪里继续？

重新登录，从工作台进入原任务。系统从最后一个保存成功且确认的步骤继续。恢复后先核对现场状态，再继续操作。

#### 13.7.3 如何反馈系统问题？

记录发生时间、当前角色、页面名称、任务或业务编号、操作步骤、页面提示和请求编号，并提供不含密码或敏感凭据的截图。将信息提交给系统维护人员。

### 14.3 主要故障领域速查

系统知识库、案例和知识图谱覆盖多个工控机故障领域。典型分类如下：

| 故障领域 | 典型现象或问题 | 主要检查方向 |
| --- | --- | --- |
| 环境工况异常 | 温度超标、低温无加温、凝露、粉尘堵塞、振动冲击 | 温湿度、进出风、滤网、机柜环境、安装固定 |
| 供电系统故障 | 外部电压异常、接地异常、电源老化、保险或接线问题 | 输入输出电压、接地、电源模块、配电部件和监测接口 |
| 散热系统故障 | 温度告警、风扇低速、停转、异响、风道受阻 | 滤网、风道、风扇、接线、散热器和温度趋势 |
| 存储系统故障 | 硬盘告警、读写错误、启动失败、容量异常 | 存储设备状态、连接、文件系统、启动项和数据保护 |
| 主板与底板故障 | 无法启动、扩展卡异常、接口失效、静电损伤 | 主板、底板、插槽、扩展卡、接口和供电 |
| 通信与监控故障 | 通信中断、远程监控失效、告警持续或无法复位 | 网络接口、通信链路、SMBus/PMBus、告警模块和配置 |
| 外设与接口故障 | 外设无法识别、显示或输入异常、连接不稳定 | 接口定义、线缆、驱动、供电和外设状态 |
| 人为运维问题 | 安装错误、维护违规、参数配置错误、配件混用 | 安装方向、操作记录、配置、备件和维护制度 |

故障分类用于检索和组织知识，不代替对具体设备、现场现象和证据的判断。
