# 工业设备智能检修系统演示视频口播稿

## 使用说明

- 目标成片：6 分 40 秒至 6 分 50 秒，不超过 7 分钟；
- 片头和片尾各预留 10 秒动画，两段均不安排口播；
- 方括号中的内容为画面提示，不需要朗读；
- 正文可直接用于真人配音或语音合成；
- 建议语速保持自然、清楚，重要数值和状态变化适当停顿；
- 实际录制时以画面完成关键操作为准，页面等待部分可后期加速。
- 全片以多 Agent 协同完成资料收集、设备识别、异常研判、步骤生成和知识存储为主线，不展开与传统对话式大模型的比较。

## 02:20—03:10　检修向导与当前步骤智能问答

Agent 自动总结生成分步骤检修向导，并根据知识库内容，为不同步骤选择相应的设备图、风道图、滤网图和接口图。每一步都给出操作目标、检查标准和安全边界。

在安全准备步骤，工程师可发起与专家的视频会诊，复杂问题由现场与专家协同处理。系统还接入语音模型，将当前步骤、安全提示和操作要点转化为语音向导。

检修过程中如有任何疑问，都可以向当前步骤的检修智能体提问。在“检查滤网、风扇和接线”步骤，工程师询问 FAN1 的接线顺序，Agent 综合设备信息、当前步骤、用户手册和知识库依据生成回答。该段操作将加速展示，保留提问、检索、答案和依据来源。
